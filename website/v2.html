Cartesian XY + Z Gripper

Two NEMA 17 stepper motors on GT2 belts move the gantry; two MG90S metal-gear servos control vertical stroke and parallel gripper jaws.

Designated Color Bins

Four color-coded bins (Red, Yellow, Green, Blue) positioned outside the active grid area for unobstructed sorting.

Fail-Safe Comms Recovery

If UART communication between Pi Zero 2 W and Mega drops mid-pick, the Mega autonomously finishes depositing the held cap, retracts Z, and parks safely.

Why Keep the Arduino Mega 2560 Alongside the Raspberry Pi Zero 2 W? The Raspberry Pi Zero 2 W runs a multitasking Linux kernel where background OS interrupts can introduce 50–500 µs timing jitter on GPIO pins—which causes stepper motors to stutter or miss steps at high speeds. By keeping the Arduino Mega 2560 as a dedicated real-time motion coprocessor, stepper acceleration ramps remain deterministic while a hardwired dual-pole E-stop cuts actuator power independently of software.

Dedicated high-current buck converter feeds PCA9685 V+ power terminal. Absorbs sudden 1.5A stall current spikes from gripper jaws.

  • • PCA9685 V+ terminal
  • • MG90S #1 (Z-axis linkage)
  • • MG90S #2 (Gripper jaws)
Power Branch C 5V / 3A Regulated

Pi Zero 2 W, 3.5" LCD & Mega Logic

Separate regulated 5V logic rail (common star GND — not galvanically isolated) powering Pi Zero 2 W via Micro-USB PWR IN (since the 3.5" LCD covers Header Pins 1–26), Arduino Mega 5V pin, and PCA9685 VCC. Peak Branch C draw ≈ 1.4 A (including ~160 mA LCD backlight & ~30 mA CH9102); verify wire gauges (≥20 AWG to PWR IN), fuses & voltage drop.

  • • Pi Zero 2 W via Micro-USB PWR IN (NOT blocked Pins 2/4/6!)
  • • 3.5" SPI LCD (~160 mA) & IMX219 CSI + OTG CH9102 (~30 mA) fed via Pi
  • • Arduino Mega 2560 5V pin (NOT VIN; avoid USB backfeed) & PCA9685 VCC
MANDATORY USB-TTL (CH9102 / CP2102) & 3.3V ⇄ 5V LEVEL SHIFTER SAFETY RULES: Because the 3.5" SPI LCD occupies Pi GPIO pins 1–26, UART connects via the Pi's inner USB OTG port → CP2102 / CH9102 USB-to-TTL module. Affordable CH9102/CP2102 modules run at 3.3V UART logic, whereas Arduino Mega 2560 Serial1 operates at 5.0V TTL (V_IH ≥ 3.0V). Route BOTH TXD and RXD through the 4-channel bidirectional level shifter (LV ← converter 3V3 pin, HV ← Mega 5V). NEVER connect the converter's +5V pin to the Mega 5V rail—it is wired to Pi USB OTG VBUS and would cause power-rail backfeed!

class _GuardedHeartbeatSupervisor:
    """
    Dedicated guarded background heartbeat thread for V2 closed-loop sessions.

    Prevents transient camera capture or OpenCV spikes (>1.2 s) from spuriously
    tripping Mega's UART comms watchdog while refusing blind heartbeating:
      - The main vision thread MUST refresh a bounded liveness deadline before
        each capture/detect stage (<= max_stall_s, default 3.5 s).
      - If the main thread genuinely stalls past that deadline, this thread
        immediately stops sending CMD_HEARTBEAT_PING (0xF0) and sets
        vision_stalled=True so Mega executes its safe park-and-halt policy.
      - Any serial I/O failure sets link_lost=True and stops immediately.
    """

    def __init__(
        self,
        controller,
        interval_s: float = HEARTBEAT_INTERVAL_S,
        max_stall_s: float = MAX_VISION_STAGE_STALL_S,
        clock=time.monotonic,
    ):
        self.controller = controller
        self.interval_s = max(0.02, float(interval_s))
        self.max_stall_s = max(0.1, float(max_stall_s))
        self.clock = clock
        self._stop_evt = threading.Event()
        self._state_lock = threading.Lock()
        self._liveness_deadline = self.clock() + self.max_stall_s
        self._thread = None
        self.vision_stalled = False
        self.link_lost = False
        self.pings_sent = 0

    def refresh_liveness(self, budget_s: float = None):
        budget = self.max_stall_s if budget_s is None else max(0.1, float(budget_s))
        with self._state_lock:
            self._liveness_deadline = self.clock() + budget

    def _run(self):
        while not self._stop_evt.is_set():
            with self._state_lock:
                deadline = self._liveness_deadline
            if self.clock() > deadline:
                self.vision_stalled = True
                print(
                    f"[WATCHDOG] Vision main thread exceeded {self.max_stall_s:.2f}s liveness budget; "
                    "stopping heartbeat so Mega enters fail-safe halt.",
                    file=sys.stderr,
                )
                self._stop_evt.set()
                return
            try:
                self.controller._uart_write(bytes([CMD_HEARTBEAT_PING]))
                self.pings_sent += 1
            except SERIAL_EXCEPTIONS:
                self.link_lost = True
                self.controller._close_serial()
                self._stop_evt.set()
                return
            self._stop_evt.wait(self.interval_s)

    def start(self):
        if self._thread is not None:
            return
        self.refresh_liveness()
        self._stop_evt.clear()
        self._thread = threading.Thread(target=self._run, name="mega_guarded_heartbeat", daemon=True)
        self._thread.start()

    def stop(self):
        self._stop_evt.set()
        if self._thread is not None:
            self._thread.join(timeout=1.0)
            self._thread = None


def resolve_serial_port(
    port_spec: str = DEFAULT_SERIAL_PORT,
    exists_fn=os.path.exists,
    glob_fn=glob.glob,
) -> str:
    """
    Resolves the Arduino Mega serial interface path.
    In 'auto' mode, prefers the persistent udev symlink (/dev/capsorter_mega)
    for Micro-USB OTG CH9102/CP2102 converters, then USB-serial devices
    (/dev/serial/by-id/*, /dev/ttyUSB*, /dev/ttyACM*), falling back to
    legacy /dev/serial0 if no USB-TTL adapter is present.
    """
    if port_spec and port_spec != "auto":
        return str(port_spec)

    if exists_fn("/dev/capsorter_mega"):
        return "/dev/capsorter_mega"

    by_id = sorted(glob_fn("/dev/serial/by-id/*"))
    preferred_tokens = ("ch9102", "ch343", "ch340", "cp210", "1a86", "10c4", "silicon_labs", "wch")
    for path in by_id:
        low = os.path.basename(path).lower()
        if any(tok in low for tok in preferred_tokens):
            return path
    if by_id:
        return by_id[0]

    for pattern in ("/dev/ttyUSB*", "/dev/ttyACM*"):
        matches = sorted(glob_fn(pattern))
        if matches:
            return matches[0]

    return "/dev/serial0"


def crc16_ccitt(data: bytes) -> int:
    crc = 0xFFFF
    for b in data:
        crc ^= (b << 8)
        for _ in range(8):
            crc = ((crc << 1) ^ 0x1021) & 0xFFFF if (crc & 0x8000) else (crc << 1) & 0xFFFF
    return crc


def load_and_validate_calibration(
    calib_file: str,
    expected_camera_type: str,
    expected_size: tuple,
) -> dict:
    """
    Fail-closed calibration loader. Refuses missing files, uncalibrated placeholders,
    mismatched camera types (e.g. CSI calibration on USB webcam), resolution mismatches,
    or malformed/non-finite matrices.
    """
    if not calib_file or not os.path.isfile(calib_file):
        raise CalibrationError(
            f"Calibration file not found: '{calib_file}'. "
            f"Run fisheye_calibrate.py for camera_type='{expected_camera_type}' before enabling motion."
        )

    try:
        cal = np.load(calib_file, allow_pickle=False)
    except Exception as exc:
        raise CalibrationError(f"Failed to read calibration archive '{calib_file}': {exc}") from exc

    required = ("K", "D", "H", "camera_type", "lens_model", "image_size", "calibrated")
    missing = [k for k in required if k not in cal.files]
    if missing:
        raise CalibrationError(
            f"Calibration file '{calib_file}' is missing required keys {missing}. "
            "Re-generate with fisheye_calibrate.py."
        )

    is_calibrated = bool(np.asarray(cal["calibrated"]).item())
    if not is_calibrated:
        raise CalibrationError(
            f"Calibration file '{calib_file}' is marked uncalibrated (calibrated=False). "
            "Motion inhibited until real checkerboard + fiducial calibration is completed."
        )

    cal_camera_type = str(np.asarray(cal["camera_type"]).item())
    if cal_camera_type != expected_camera_type:
        raise CalibrationError(
            f"Calibration camera_type mismatch: file has '{cal_camera_type}', "
            f"but active camera is '{expected_camera_type}'. Use a calibration file "
            "captured on this exact camera and lens."
        )

    lens_model = str(np.asarray(cal["lens_model"]).item())
    if lens_model not in ("fisheye", "pinhole"):
        raise CalibrationError(f"Unsupported lens_model '{lens_model}' in '{calib_file}'.")

    cal_size = tuple(int(v) for v in np.asarray(cal["image_size"]).reshape(-1))
    if cal_size != tuple(expected_size):
        raise CalibrationError(
            f"Calibration image_size {cal_size} does not match configured capture size {tuple(expected_size)}."
        )

    try:
        K = np.asarray(cal["K"], dtype=np.float64).reshape((3, 3))
        H = np.asarray(cal["H"], dtype=np.float64).reshape((3, 3))
        D = np.asarray(cal["D"], dtype=np.float64).reshape((-1, 1))
    except ValueError as exc:
        raise CalibrationError(f"Invalid matrix dimensions in '{calib_file}': {exc}") from exc

    if lens_model == "fisheye" and D.shape != (4, 1):
        raise CalibrationError(f"Fisheye distortion vector D must have shape (4, 1), got {D.shape}.")
    if lens_model == "pinhole" and D.shape[0] < 4:
        raise CalibrationError(f"Pinhole distortion vector D must have >=4 coefficients, got {D.shape}.")

    if not (np.all(np.isfinite(K)) and np.all(np.isfinite(D)) and np.all(np.isfinite(H))):
        raise CalibrationError(f"Calibration matrices in '{calib_file}' contain NaN or Inf values.")
    if abs(np.linalg.det(H)) < 1e-12:
        raise CalibrationError(f"Homography matrix H in '{calib_file}' is singular.")

    camera_height_mm = (
        float(np.asarray(cal["camera_height_mm"]).item())
        if "camera_height_mm" in cal.files else 0.0
    )
    cap_height_mm = (
        float(np.asarray(cal["cap_height_mm"]).item())
        if "cap_height_mm" in cal.files else 13.0
    )
    if not (math.isfinite(camera_height_mm) and math.isfinite(cap_height_mm)):
        raise CalibrationError(f"Non-finite parallax heights in '{calib_file}'.")

    return {
        "K": K,
        "D": D,
        "H": H,
        "camera_type": cal_camera_type,
        "lens_model": lens_model,
        "image_size": cal_size,
        "camera_height_mm": camera_height_mm,
        "cap_height_mm": cap_height_mm,
    }


def _circle_intersects_rect(cx: float, cy: float, radius: float, x0: float, y0: float, x1: float, y1: float) -> bool:
    """Exact 2D circle vs axis-aligned rectangle intersection check."""
    nearest_x = min(max(cx, x0), x1)
    nearest_y = min(max(cy, y0), y1)
    dx = cx - nearest_x
    dy = cy - nearest_y
    return (dx * dx + dy * dy) < (radius * radius)

                self.picam2.set_controls(lock_ctrls)
            else:
                self.usb_cam = cv2.VideoCapture(0)
                if not self.usb_cam.isOpened():
                    raise RuntimeError("Failed to open USB camera device 0.")
                self.usb_cam.set(cv2.CAP_PROP_BUFFERSIZE, 1)
                self.usb_cam.set(cv2.CAP_PROP_FRAME_WIDTH, self.width)
                self.usb_cam.set(cv2.CAP_PROP_FRAME_HEIGHT, self.height)

    def _estimate_px_per_mm(self) -> float:
        pts_mm = np.array([[[150.0, 150.0]], [[170.0, 150.0]], [[150.0, 170.0]]], dtype=np.float32)
        uv = cv2.perspectiveTransform(pts_mm, self.H_inv).reshape(3, 2)
        dx = float(np.linalg.norm(uv[1] - uv[0])) / 20.0
        dy = float(np.linalg.norm(uv[2] - uv[0])) / 20.0
        scale = 0.5 * (dx + dy)
        return scale if (math.isfinite(scale) and scale > 0.2) else 1.5

    def _estimate_optical_center_board_mm(self) -> tuple:
        cx_px, cy_px = float(self.K[0, 2]), float(self.K[1, 2])
        pt = np.array([[[cx_px, cy_px]]], dtype=np.float32)
        mapped = cv2.perspectiveTransform(pt, self.H)[0][0]
        bx, by = float(mapped[0]), float(mapped[1])
        if math.isfinite(bx) and math.isfinite(by) and -50.0 <= bx <= 350.0 and -50.0 <= by <= 350.0:
            return (bx, by)
        return (BOARD_SIZE_MM * 0.5, BOARD_SIZE_MM * 0.5)

    def apply_parallax_correction(self, x_mm: float, y_mm: float) -> tuple:
        """
        Compensates outward radial parallax caused by cap height (h_cap ~ 13 mm)
        relative to the Z=0 calibrated board plane when viewed from overhead H_cam.
        Disabled automatically if camera_height_mm <= cap_height_mm or <= 0.
        """
        if self.camera_height_mm > self.cap_height_mm > 0.0:
            scale = 1.0 - (self.cap_height_mm / self.camera_height_mm)
            cx, cy = self.cam_center_board_mm
            return (cx + (x_mm - cx) * scale, cy + (y_mm - cy) * scale)
        return (x_mm, y_mm)

    def undistort_frame(self, raw_bgr: np.ndarray) -> np.ndarray:
        return cv2.remap(raw_bgr, self.map1, self.map2, interpolation=cv2.INTER_LINEAR)

    def capture_rectified_frame(self) -> np.ndarray:
        if self.picam2 is not None:
            raw = self.picam2.capture_array("main")
        elif self.usb_cam is not None:
            for _ in range(4):
                self.usb_cam.grab()
            ok, raw = self.usb_cam.read()
            if not ok:
                raise RuntimeError("USB camera frame acquisition failed")
        else:
            raise RuntimeError("No active camera hardware initialized")
        if raw.shape[1] != self.width or raw.shape[0] != self.height:
            raise CalibrationError(
                f"Captured frame size {(raw.shape[1], raw.shape[0])} does not match "
                f"calibrated resolution {(self.width, self.height)}."
            )
        return self.undistort_frame(raw)

    def _split_touching_cap_contour(self, cnt: np.ndarray, binary_mask: np.ndarray) -> list:
        """
        Separates merged contours of 2+ touching same-color caps (pairs, triangles,
        grids) using Euclidean distance transform + local peak extraction while
        preserving interior plywood gaps between touching caps.
        """
        x, y, w, h = cv2.boundingRect(cnt)
        pad = 2
        contour_roi = np.zeros((h + 2 * pad, w + 2 * pad), dtype=np.uint8)
        shifted = cnt - np.array([[[x - pad, y - pad]]], dtype=cnt.dtype)
        cv2.drawContours(contour_roi, [shifted], -1, 255, cv2.FILLED)

        # Intersect with actual binary_mask so interior gaps (e.g. center of 3 touching caps) remain 0
        roi = np.zeros_like(contour_roi)
        roi[pad:pad + h, pad:pad + w] = binary_mask[y:y + h, x:x + w]
        roi = cv2.bitwise_and(roi, contour_roi)

        dist = cv2.distanceTransform(roi, cv2.DIST_L2, 5)
        dist_smooth = cv2.GaussianBlur(dist, (5, 5), 1.0)

        min_peak_val = max(4.0, 0.45 * self.expected_cap_radius_px)
        k_size = max(5, int(round(self.expected_cap_radius_px * 0.55)) | 1)
        kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (k_size, k_size))
        dilated = cv2.dilate(dist_smooth, kernel)

        peak_mask = ((dist_smooth >= dilated - 1e-4) & (dist >= min_peak_val)).astype(np.uint8)
        num_labels, _, _, centroids = cv2.connectedComponentsWithStats(peak_mask)

        peaks = []
        for lbl in range(1, num_labels):
            px, py = float(centroids[lbl][0]), float(centroids[lbl][1])
            ix = min(max(int(round(px)), 0), dist.shape[1] - 1)
            iy = min(max(int(round(py)), 0), dist.shape[0] - 1)
            r_val = float(dist[iy, ix])
            if r_val >= min_peak_val:
                peaks.append((px + x - pad, py + y - pad, r_val))

        # Suppress secondary sub-peaks closer than 1.25 * expected_cap_radius_px
        peaks.sort(key=lambda p: p[2], reverse=True)
        min_sep_px = max(8.0, 1.25 * self.expected_cap_radius_px)
        kept = []
        for u, v, r_val in peaks:
            if any(math.hypot(u - ku, v - kv) < min_sep_px for ku, kv, _ in kept):
                continue
            kept.append((u, v, math.pi * r_val * r_val))
        return kept

    def deduplicate_spatial_nms(self, candidates: list) -> list:
        sorted_cands = sorted(candidates, key=lambda c: c.get("_area", 0.0), reverse=True)
        accepted = []
        for cand in sorted_cands:
            if any(
                math.hypot(cand["boardX_mm"] - a["boardX_mm"],
                           cand["boardY_mm"] - a["boardY_mm"]) < MIN_CAP_SEPARATION_MM
                for a in accepted
            ):
                continue
            item = {k: v for k, v in cand.items() if k != "_area"}
            item["capId"] = len(accepted) + 1
            accepted.append(item)
        return accepted[:MAX_BATCH_CAPS]

    def detect_caps(self, rectified_bgr: np.ndarray, occluded_y_mm: float = None) -> list:
        """
        Detects bottle caps at arbitrary continuous (X, Y) coordinates on the 300x300 mm
        board, splitting touching same-color clusters, compensating radial cap-height
        parallax, masking the gantry bridge band during bin-side scans, and tagging
        safe mechanical reachability (`in_safe_bounds`).
        """
        hsv = cv2.cvtColor(rectified_bgr, cv2.COLOR_BGR2HSV)
        candidates = []

        nominal_area = math.pi * (self.expected_cap_radius_px ** 2)
        min_cap_area = max(350.0, 0.32 * nominal_area)
        max_single_area = max(2400.0, 1.65 * nominal_area)

        for color_id, ranges in HSV_RANGES.items():
            mask = np.zeros((self.height, self.width), dtype=np.uint8)
            for lower, upper in ranges:
                mask |= cv2.inRange(hsv, np.array(lower, dtype=np.uint8), np.array(upper, dtype=np.uint8))

            mask_opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN, self.kernel_open)
            mask_closed = cv2.morphologyEx(mask_opened, cv2.MORPH_CLOSE, self.kernel_close)
            contours, _ = cv2.findContours(mask_closed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

            for cnt in contours:
                area = cv2.contourArea(cnt)
                if area < min_cap_area:
                    continue
                perim = cv2.arcLength(cnt, True)
                circularity = (4.0 * math.pi * area) / (perim * perim + 1e-5)

                extracted = []
                if area <= max_single_area and circularity >= 0.72:
                    M = cv2.moments(cnt)
                    if M["m00"] > 0:
                        extracted.append((M["m10"] / M["m00"], M["m01"] / M["m00"], area))
                else:
                    # Merged same-color cluster or distorted silhouette -> distance-transform split
                    extracted.extend(self._split_touching_cap_contour(cnt, mask_opened))

                for u, v, est_area in extracted:
                    pt = np.array([[[u, v]]], dtype=np.float32)
                    board_pt = cv2.perspectiveTransform(pt, self.H)[0][0]
                    x_mm, y_mm = self.apply_parallax_correction(float(board_pt[0]), float(board_pt[1]))

                    if not (0.0 <= x_mm <= BOARD_SIZE_MM and 0.0 <= y_mm <= BOARD_SIZE_MM):
                        continue

                    # Ignore detections inside horizontal gantry bridge occlusion strip at bin
                    if (
                        occluded_y_mm is not None
                        and self.bridge_occlusion_half_mm > 0.0
                        and abs(y_mm - occluded_y_mm) <= self.bridge_occlusion_half_mm
                    ):
                        continue

                    in_safe = (
                        SAFE_PICK_MIN_X_MM <= x_mm <= SAFE_PICK_MAX_X_MM
                        and SAFE_PICK_MIN_Y_MM <= y_mm <= SAFE_PICK_MAX_Y_MM
                    )
                    _, _, bin_id = BIN_COORDS[color_id]
                    candidates.append({
                        "capId": 0,
                        "color": color_id,
                        "pixelX": int(round(u)),
                        "pixelY": int(round(v)),
                        "boardX_mm": x_mm,
                        "boardY_mm": y_mm,
                        "targetBinId": bin_id,
                        "in_safe_bounds": in_safe,
                        "_area": est_area,
                    })
        return self.deduplicate_spatial_nms(candidates)

    def count_jaw_collisions(self, target_cap: dict, all_caps: list) -> tuple:
        """
        Evaluates how many sides (0, 1, or 2) of the descending open parallel gripper
        jaws collide with neighboring caps along `self.jaw_axis`.
        Returns (blocked_sides, min_neighbor_dist_mm).
        """
        tx, ty = target_cap["boardX_mm"], target_cap["boardY_mm"]
        r_check = CAP_RADIUS_MM + JAW_CLEARANCE_PAD_MM
        neg_blocked = False
        pos_blocked = False
        min_dist = 1e9

        for other in all_caps:
            if other is target_cap:
                continue
            ox, oy = other["boardX_mm"], other["boardY_mm"]
            d = math.hypot(ox - tx, oy - ty)
            if d < 1e-3:
                continue
            if d < min_dist:
                min_dist = d

            if self.jaw_axis == "X":
                if not neg_blocked and _circle_intersects_rect(
                    ox, oy, r_check,
                    tx - JAW_OUTER_HALF_MM, ty - JAW_WIDTH_HALF_MM,
                    tx - JAW_INNER_HALF_MM, ty + JAW_WIDTH_HALF_MM,
                ):
                    neg_blocked = True
                if not pos_blocked and _circle_intersects_rect(
                    ox, oy, r_check,
                    tx + JAW_INNER_HALF_MM, ty - JAW_WIDTH_HALF_MM,
                    tx + JAW_OUTER_HALF_MM, ty + JAW_WIDTH_HALF_MM,
                ):
                    pos_blocked = True
            else:
                if not neg_blocked and _circle_intersects_rect(
                    ox, oy, r_check,
                    tx - JAW_WIDTH_HALF_MM, ty - JAW_OUTER_HALF_MM,
                    tx + JAW_WIDTH_HALF_MM, ty - JAW_INNER_HALF_MM,
                ):
                    neg_blocked = True
                if not pos_blocked and _circle_intersects_rect(
                    ox, oy, r_check,
                    tx - JAW_WIDTH_HALF_MM, ty + JAW_INNER_HALF_MM,
                    tx + JAW_WIDTH_HALF_MM, ty + JAW_OUTER_HALF_MM,
                ):
                    pos_blocked = True

        return (int(neg_blocked) + int(pos_blocked), min_dist)

    def select_next_cap(
        self,
        detected_caps: list,
        cur_xy: tuple = (0.0, 0.0),
        retry_records: list = None,
        quarantined_zones: list = None,
    ):
        """
        Clearance-first / outermost-first pick selector:
          1. Excludes caps outside safe mechanical reach (`in_safe_bounds == False`)
             and quarantined unpickable spots, while STILL checking them as obstacles.
          2. Priority order: (retry_penalty, blocked_sides, travel_dist, -min_neighbor_dist).
             Picks completely clear caps first, peels clusters from outside in, and
             minimizes Cartesian travel from the current bin.
        """
        retry_records = retry_records or []
        quarantined_zones = quarantined_zones or []
        cur_x, cur_y = float(cur_xy[0]), float(cur_xy[1])

        scored = []
        for cap in detected_caps:
            if not cap.get("in_safe_bounds", True):
                continue
            cx, cy, col = cap["boardX_mm"], cap["boardY_mm"], cap["color"]
            if any(
                q["color"] == col and math.hypot(cx - q["x"], cy - q["y"]) <= MISSED_PICK_RADIUS_MM
                for q in quarantined_zones
            ):
                continue

            retry_penalty = 1 if any(
                r["color"] == col and r["count"] > 0
                and math.hypot(cx - r["x"], cy - r["y"]) <= MISSED_PICK_RADIUS_MM
                for r in retry_records
            ) else 0

            blocked_sides, min_neighbor = self.count_jaw_collisions(cap, detected_caps)
            travel = math.hypot(cx - cur_x, cy - cur_y)
            scored.append(((retry_penalty, blocked_sides, travel, -min_neighbor), blocked_sides, cap))

        if not scored:
            return None

        scored.sort(key=lambda item: item[0])
        _, blocked_sides, best = scored[0]
        chosen = dict(best)
        chosen["blocked_sides"] = blocked_sides
        return chosen

    def _update_retry_state(
        self,
        last_target: dict,
        detected_caps: list,
        retry_records: list,
        quarantined_zones: list,
        occluded_y_mm: float = None,
    ) -> bool:
        """
        Checks whether `last_target` is still sitting at its previous location on an
        unoccluded region of the fresh scan. Quarantines spots after MAX_PICK_RETRIES.
        Returns True if `last_target` was visibly evaluated (not occluded), False otherwise.
        """
        if last_target is None:
            return False
        tx, ty, col = last_target["boardX_mm"], last_target["boardY_mm"], last_target["color"]

        # Do not judge pick outcome while last_target sits inside the masked bridge strip
        if (
            occluded_y_mm is not None
            and self.bridge_occlusion_half_mm > 0.0
            and abs(ty - occluded_y_mm) <= self.bridge_occlusion_half_mm
        ):
            return False

        already_quarantined = any(
            q["color"] == col and math.hypot(q["x"] - tx, q["y"] - ty) <= MISSED_PICK_RADIUS_MM
            for q in quarantined_zones
        )
        if already_quarantined:
            return True

        still_present = any(
            c["color"] == col and math.hypot(c["boardX_mm"] - tx, c["boardY_mm"] - ty) <= MISSED_PICK_RADIUS_MM
            for c in detected_caps
        )
        self._last_pick_missed = bool(still_present)

        rec = next(
            (r for r in retry_records
             if r["color"] == col and math.hypot(r["x"] - tx, r["y"] - ty) <= MISSED_PICK_RADIUS_MM),
            None,
        )

        if still_present:
            if rec is None:
                rec = {"x": tx, "y": ty, "color": col, "count": 1}
                retry_records.append(rec)
            else:
                rec["x"], rec["y"] = tx, ty
                rec["count"] += 1
            if rec["count"] >= MAX_PICK_RETRIES:
                quarantined_zones.append({"x": tx, "y": ty, "color": col, "attempts": rec["count"]})
                print(
                    f"[WARN] Cap (color={col}) at ({tx:.1f}, {ty:.1f}) mm still present after "
                    f"{rec['count']} attempts; quarantining spot for this session.",
                    file=sys.stderr,
                )
        elif rec is not None:
            retry_records.remove(rec)
        return True

    def optimize_path(self, caps: list) -> list:
        """Legacy greedy path optimizer (retained for offline tools & unit tests)."""
        ordered, remaining = [], [dict(c) for c in caps]
        cur_x, cur_y = 0.0, 0.0
        seq_id = 1
        while remaining:
            remaining.sort(key=lambda c: math.hypot(c["boardX_mm"] - cur_x, c["boardY_mm"] - cur_y))
            nxt = remaining.pop(0)
            nxt["capId"] = seq_id
            seq_id += 1
            ordered.append(nxt)
            cur_x, cur_y, _ = BIN_COORDS[nxt["color"]]
        return ordered

    def pack_single_target_packet(self, cap: dict) -> bytes:
        """
        Packs an 18-byte CRC16-verified closed-loop single-target packet:
          [0x5B][CapTarget: <BBHHffB (15B)][CRC16: <H (2B)]
        """
        payload = struct.pack(
            "<BBHHffB",
            int(cap.get("capId", 1)) & 0xFF,
            int(cap["color"]) & 0xFF,
            int(cap["pixelX"]) & 0xFFFF,
            int(cap["pixelY"]) & 0xFFFF,
            float(cap["boardX_mm"]),
            float(cap["boardY_mm"]),
            int(cap["targetBinId"]) & 0xFF,
        )
        crc = crc16_ccitt(payload)
        return bytes([PROTOCOL_SINGLE_MAGIC]) + payload + struct.pack("<H", crc)

    def pack_batch_packet(self, ordered_caps: list) -> bytes:
        if not (1 <= len(ordered_caps) <= MAX_BATCH_CAPS):
            raise ValueError(f"Batch size must be in 1..{MAX_BATCH_CAPS}, got {len(ordered_caps)}")
        payload = bytearray()
        for c in ordered_caps:
            # Matches struct CapTarget: <BBHHffB (15 bytes packed)
            payload += struct.pack(
                "<BBHHffB",
                c["capId"], c["color"], c["pixelX"], c["pixelY"],
                c["boardX_mm"], c["boardY_mm"], c["targetBinId"],
            )
        crc = crc16_ccitt(bytes(payload))
        # Matches struct BatchHeader: <BHBH (6 bytes packed)
        header = struct.pack("<BHBH", PROTOCOL_MAGIC_BYTE, self.batch_id, len(ordered_caps), crc)
        self.batch_id = ((self.batch_id + 1) & 0xFFFF) or 1
        return header + bytes(payload)

    def _emit_hud(self, event: str, payload: dict = None):
        if self.state_callback is not None:
            try:
                self.state_callback(event, payload or {})
            except Exception:
                pass

    def _close_serial(self):
        with self._uart_lock:
            if self.uart is not None:
                try:
                    if hasattr(self.uart, "close"):
                        self.uart.close()
                except Exception:
                    pass
                self.uart = None

    def _uart_write(self, data: bytes):
        with self._uart_lock:
            if self.uart is None:
                raise OSError("Serial port closed")
            self.uart.write(data)
            self.uart.flush()

    def reconnect_serial(self) -> bool:
        """
        (Re-)opens the USB-to-TTL serial bridge (Micro-USB OTG -> CH9102/CP2102)
        at 115,200 baud. Safe to call after a USB EMI drop or hot-replug.
        """
        if not HAS_PYSERIAL:
            return False
        self._close_serial()
        self.resolved_serial_port = resolve_serial_port(self.serial_port_spec)
        try:
            new_uart = serial.Serial(self.resolved_serial_port, baudrate=115200, timeout=0.5)
            with self._uart_lock:
                self.uart = new_uart
            self._emit_hud("SERIAL_OPEN", {"serial_port": self.resolved_serial_port, "link_status": "WAIT_MEGA"})
            return True
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] Failed to open '{self.resolved_serial_port}': {exc}", file=sys.stderr)
            self._close_serial()
            self._emit_hud("LINK_LOST", {"serial_port": self.resolved_serial_port, "reason": "USB-TTL OFFLINE"})
            return False

    def send_rearm_home(self) -> bool:
        """Sends explicit CMD_REARM_HOME (0xB4) triggered by operator touch button."""
        try:
            with self._uart_lock:
                if self.uart is None:
                    raise OSError("Serial port closed")
                self.uart.reset_input_buffer()
                self.uart.write(bytes([CMD_REARM_HOME]))
                self.uart.flush()
            self._emit_hud("REARMING", {})
            return True
        except SERIAL_EXCEPTIONS:
            self._close_serial()
            self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
            return False

    def write_paced_uart(self, packet: bytes, chunk_size: int = 32, sleep_fn=time.sleep):
        # Pace in 32-byte chunks with 2 ms pause so Mega's 64-byte RX ring buffer never overflows
        for offset in range(0, len(packet), chunk_size):
            self._uart_write(packet[offset:offset + chunk_size])
            if offset + chunk_size < len(packet):
                sleep_fn(0.002)

    def wait_for_mega_ready(
        self,
        timeout_s: float = None,
        poll_interval_s: float = READY_POLL_INTERVAL_S,
        clock=time.monotonic,
        sleep_fn=time.sleep,
    ) -> bool:
        """
        Explicit READY/BUSY/FAULT startup handshake. Never transmits motion data
        until Mega reports CMD_STATUS_READY after homing finishes.
        """
        if self.uart is None:
            return False

        start_t = clock()
        last_poll_t = -1e9
        try:
            while timeout_s is None or (clock() - start_t < timeout_s):
                now = clock()
                if now - last_poll_t >= poll_interval_s:
                    with self._uart_lock:
                        if self.uart is None:
                            raise OSError("Serial port closed")
                        self.uart.reset_input_buffer()
                        self.uart.write(bytes([CMD_QUERY_STATUS]))
                        self.uart.flush()
                    last_poll_t = now

                while self.uart is not None and self.uart.in_waiting > 0:
                    with self._uart_lock:
                        resp_b = self.uart.read(1) if self.uart is not None else b""
                    if not resp_b:
                        break
                    resp = resp_b[0]
                    if resp == CMD_STATUS_READY:
                        self._emit_hud("READY", {"serial_port": self.resolved_serial_port})
                        return True
                    if resp in (CMD_STATUS_FAULT, CMD_HARD_FAULT, CMD_RECOVERY_HALT):
                        print(
                            f"[FAULT] Mega reported status 0x{resp:02X}; "
                            "motion inhibited until operator clears fault & re-arms.",
                            file=sys.stderr,
                        )
                        self._emit_hud("FAULT", {"reason": f"MEGA FAULT 0x{resp:02X}"})
                        return False
                    # CMD_STATUS_BUSY: keep polling until Mega finishes homing

                sleep_fn(0.02)
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] Serial link error during READY poll: {exc}", file=sys.stderr)
            self._close_serial()
            self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
            return False
        return False

    def _send_single_target_with_ack(self, cap: dict, sleep_fn=time.sleep) -> str:
        packet = self.pack_single_target_packet(cap)
        try:
            for _ in range(3):
                with self._uart_lock:
                    if self.uart is None:
                        raise OSError("Serial port closed")
                    self.uart.reset_input_buffer()
                    self.uart.write(packet)
                    self.uart.flush()
                ack = self.uart.read(1)
                if ack:
                    code = ack[0]
                    if code == CMD_BATCH_ACK:
                        return "ACK"
                    if code in (CMD_HARD_FAULT, CMD_RECOVERY_HALT, CMD_STATUS_FAULT):
                        return "FAULT"
                sleep_fn(0.05)
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] USB-TTL disconnect during target send: {exc}", file=sys.stderr)
            self._close_serial()
            return "LINK_LOST"
        return "NACK"

    def _await_opcode_with_heartbeat(
        self,
        target_opcode: int,
        timeout_s: float = MAX_SINGLE_CAP_S,
        clock=time.monotonic,
        sleep_fn=time.sleep,
    ) -> str:
        start_t = clock()
        try:
            while True:
                self._uart_write(bytes([CMD_HEARTBEAT_PING]))
                sleep_fn(HEARTBEAT_INTERVAL_S)

                while self.uart is not None and self.uart.in_waiting > 0:
                    with self._uart_lock:
                        resp_b = self.uart.read(1) if self.uart is not None else b""
                    if not resp_b:
                        break
                    resp = resp_b[0]
                    if resp == target_opcode:
                        return "OK"
                    if resp in (CMD_RECOVERY_HALT, CMD_HARD_FAULT, CMD_STATUS_FAULT):
                        return "FAULT"

                if clock() - start_t > timeout_s:
                    return "TIMEOUT"
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] USB-TTL disconnect awaiting 0x{target_opcode:02X}: {exc}", file=sys.stderr)
            self._close_serial()
            return "LINK_LOST"

    def run_closed_loop_sort_session(
        self,
        capture_fn=None,
        clock=time.monotonic,
        sleep_fn=time.sleep,
        max_cycles: int = MAX_SESSION_CYCLES,
        enable_bg_heartbeat: bool = None,
        max_vision_stall_s: float = MAX_VISION_STAGE_STALL_S,
        heartbeat_interval_s: float = HEARTBEAT_INTERVAL_S,
    ) -> dict:
        """
        Executes a full closed-loop sorting session:
          1. Captures Scan #0 at unobstructed (0, 0).
          2. Sends one clearance-ranked CapTarget at a time via CMD_PICK_SINGLE (0x5B).
          3. On Mega CMD_SCAN_WINDOW_OPEN (0xA5) at the color bin, captures & analyzes
             the fresh board IN PARALLEL with the bin drop while a guarded background
             heartbeat thread maintains Mega's 1.2 s UART watchdog (stopping automatically
             if vision stalls beyond max_vision_stall_s).
          4. On CMD_AWAIT_NEXT (0xA6), immediately dispatches the next cap from the bin,
             or executes CMD_PARK_FOR_SCAN (0xB5) for an unobstructed clear-FOV check
             before terminating cleanly with CMD_FINISH_SESSION (0xB6).
        """
        if self.uart is None:
            return {
                "status": "NACK", "picked": 0, "scans": 0, "quarantined": [],
                "out_of_bounds_seen": 0, "max_vision_ms": 0.0,
            }

        cap_source = capture_fn or self.capture_rectified_frame
        retry_records = []
        quarantined_zones = []
        scans = 0
        picked = 0
        out_of_bounds_seen = 0
        max_vision_ms = 0.0
        total_bg_heartbeats = 0

        use_bg_hb = (
            (clock is time.monotonic and sleep_fn is time.sleep)
            if enable_bg_heartbeat is None
            else bool(enable_bg_heartbeat)
        )
        hb_sup = None

        def _stop_hb():
            nonlocal hb_sup, total_bg_heartbeats
            if hb_sup is not None:
                hb_sup.stop()
                total_bg_heartbeats += hb_sup.pings_sent
                hb_sup = None

        def _capture_and_detect_timed(occluded_y_mm):
            nonlocal scans, out_of_bounds_seen, max_vision_ms
            if hb_sup is not None:
                hb_sup.refresh_liveness(max_vision_stall_s)
            t0 = clock()
            frame_img = cap_source()
            t1 = clock()
            scans += 1
            if hb_sup is not None:
                hb_sup.refresh_liveness(max_vision_stall_s)
            else:
                self._uart_write(bytes([CMD_HEARTBEAT_PING]))
            detected_caps = self.detect_caps(frame_img, occluded_y_mm=occluded_y_mm)
            t2 = clock()
            cap_ms = max(0.0, (t1 - t0) * 1000.0)
            det_ms = max(0.0, (t2 - t1) * 1000.0)
            total_ms = cap_ms + det_ms
            if total_ms > max_vision_ms:
                max_vision_ms = total_ms
            if total_ms > BIN_DROP_BUDGET_MS:
                print(
                    f"[VISION TIMING] Frame #{scans} took {total_ms:.1f} ms "
                    f"(capture={cap_ms:.1f} ms, detect={det_ms:.1f} ms > {BIN_DROP_BUDGET_MS:.0f} ms bin budget)",
                    file=sys.stderr,
                )
            out_of_bounds_seen += sum(1 for c in detected_caps if not c.get("in_safe_bounds", True))
            if hb_sup is not None:
                hb_sup.refresh_liveness(max_vision_stall_s)
            return frame_img, detected_caps

        def _make_result(status_str: str) -> dict:
            active_pings = hb_sup.pings_sent if hb_sup is not None else 0
            return {
                "status": status_str,
                "picked": picked,
                "scans": scans,
                "quarantined": quarantined_zones,
                "out_of_bounds_seen": out_of_bounds_seen,
                "max_vision_ms": round(max_vision_ms, 2),
                "bg_heartbeats_sent": total_bg_heartbeats + active_pings,
            }

        # Scan #0: Unobstructed full-board scan while parked at (0, 0) (Mega is IDLE)
        self._emit_hud("SCAN_INITIAL", {"scans": scans})
        t0 = clock()
        frame = cap_source()
        t1 = clock()
        scans += 1
        caps = self.detect_caps(frame, occluded_y_mm=None)
        t2 = clock()
        max_vision_ms = max(max_vision_ms, max(0.0, (t2 - t0) * 1000.0))
        out_of_bounds_seen += sum(1 for c in caps if not c.get("in_safe_bounds", True))
        self._emit_hud(
            "SCAN_INITIAL",
            {"caps": caps, "scans": scans, "quarantined": quarantined_zones, "cam_frame": frame},
        )
        next_cap = self.select_next_cap(caps, (0.0, 0.0), retry_records, quarantined_zones)

        if next_cap is None:
            self._emit_hud("SESSION_COMPLETE", {"caps": caps, "picked": 0, "scans": scans})
            return _make_result("COMPLETE")

        try:
            for _ in range(max_cycles):
                _stop_hb()

                ack_status = self._send_single_target_with_ack(next_cap, sleep_fn=sleep_fn)
                if ack_status != "ACK":
                    self._emit_hud(
                        "LINK_LOST" if ack_status == "LINK_LOST" else "FAULT",
                        {"reason": f"DISPATCH {ack_status}"},
                    )
                    return _make_result(ack_status)

                if use_bg_hb:
                    hb_sup = _GuardedHeartbeatSupervisor(
                        self,
                        interval_s=heartbeat_interval_s,
                        max_stall_s=max_vision_stall_s,
                        clock=clock,
                    )
                    hb_sup.start()

                last_target = next_cap
                bin_x, bin_y, _ = BIN_COORDS[last_target["color"]]
                self._emit_hud("TARGET_DISPATCHED", {"target": last_target, "scans": scans, "picked": picked})
                cycle_start = clock()
                scanned_at_bin = False
                retry_evaluated = False
                self._last_pick_missed = False
                await_received = False
                candidate_next = None

                while not await_received:
                    if hb_sup is not None:
                        hb_sup.refresh_liveness(max_vision_stall_s)
                        if hb_sup.link_lost:
                            self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
                            return _make_result("LINK_LOST")
                        if hb_sup.vision_stalled:
                            self._emit_hud("FAULT", {"reason": "VISION STALL WATCHDOG"})
                            return _make_result("VISION_STALL")
                    else:
                        self._uart_write(bytes([CMD_HEARTBEAT_PING]))
                    sleep_fn(heartbeat_interval_s)

                    while self.uart is not None and self.uart.in_waiting > 0:
                        with self._uart_lock:
                            resp_b = self.uart.read(1) if self.uart is not None else b""
                        if not resp_b:
                            break
                        resp = resp_b[0]
                        if resp == CMD_SCAN_WINDOW_OPEN and not scanned_at_bin:
                            # Pipelined capture while Mega lowers/drops/retracts at color bin
                            self._emit_hud("SCAN_WINDOW_OPEN", {"bin_y": bin_y})
                            fresh, fresh_caps = _capture_and_detect_timed(occluded_y_mm=bin_y)
                            scanned_at_bin = True
                            if hb_sup is not None and hb_sup.vision_stalled:
                                self._emit_hud("FAULT", {"reason": "VISION STALL WATCHDOG"})
                                return _make_result("VISION_STALL")
                            if hb_sup is not None and hb_sup.link_lost:
                                self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
                                return _make_result("LINK_LOST")
                            retry_evaluated = self._update_retry_state(
                                last_target, fresh_caps, retry_records, quarantined_zones, occluded_y_mm=bin_y
                            )
                            self._emit_hud(
                                "SCAN_WINDOW_OPEN",
                                {
                                    "bin_y": bin_y,
                                    "caps": fresh_caps,
                                    "scans": scans,
                                    "quarantined": quarantined_zones,
                                    "cam_frame": fresh,
                                },
                            )
                            candidate_next = self.select_next_cap(
                                fresh_caps, (bin_x, bin_y), retry_records, quarantined_zones
                            )
                        elif resp == CMD_CAP_PROGRESS:
                            cycle_start = clock()
                        elif resp == CMD_AWAIT_NEXT:
                            await_received = True
                            break
                        elif resp in (CMD_RECOVERY_HALT, CMD_HARD_FAULT, CMD_STATUS_FAULT):
                            self._emit_hud("FAULT", {"reason": f"MEGA FAULT 0x{resp:02X}"})
                            return _make_result("FAULT")

                    if not await_received and (clock() - cycle_start > MAX_SINGLE_CAP_S):
                        print("[TIMEOUT] Mega stopped responding during closed-loop cap cycle.", file=sys.stderr)
                        self._emit_hud("TIMEOUT", {"reason": "CYCLE TIMEOUT"})
                        return _make_result("TIMEOUT")

                # Fallback capture if Mega signaled AWAIT_NEXT without prior SCAN_WINDOW_OPEN
                if not scanned_at_bin:
                    fresh, fresh_caps = _capture_and_detect_timed(occluded_y_mm=bin_y)
                    if hb_sup is not None and hb_sup.vision_stalled:
                        self._emit_hud("FAULT", {"reason": "VISION STALL WATCHDOG"})
                        return _make_result("VISION_STALL")
                    if hb_sup is not None and hb_sup.link_lost:
                        self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
                        return _make_result("LINK_LOST")
                    retry_evaluated = self._update_retry_state(
                        last_target, fresh_caps, retry_records, quarantined_zones, occluded_y_mm=bin_y
                    )
                    self._emit_hud(
                        "AWAIT_NEXT",
                        {
                            "at_xy": (bin_x, bin_y),
                            "caps": fresh_caps,
                            "scans": scans,
                            "quarantined": quarantined_zones,
                            "cam_frame": fresh,
                        },
                    )
                    candidate_next = self.select_next_cap(
                        fresh_caps, (bin_x, bin_y), retry_records, quarantined_zones
                    )

                if not self._last_pick_missed:
                    picked += 1
                    self._emit_hud("CAP_SORTED", {"color": last_target["color"], "picked": picked})
                self._emit_hud("AWAIT_NEXT", {"at_xy": (bin_x, bin_y), "picked": picked})

                # Honor operator LCD PAUSE cleanly between caps by parking at (0,0) into STATE_IDLE
                if self.paused:
                    _stop_hb()
                    self._emit_hud("FINISH_SESSION", {})
                    self._uart_write(bytes([CMD_FINISH_SESSION]))
                    done_res = self._await_opcode_with_heartbeat(
                        CMD_BATCH_COMPLETE, timeout_s=MAX_SINGLE_CAP_S, clock=clock, sleep_fn=sleep_fn
                    )
                    final_status = "PAUSED" if done_res == "OK" else done_res
                    self._emit_hud(
                        "PAUSED" if final_status == "PAUSED" else (
                            "LINK_LOST" if final_status == "LINK_LOST" else "FAULT"
                        ),
                        {"picked": picked, "scans": scans, "reason": final_status},
                    )
                    return _make_result(final_status)

                if candidate_next is not None:
                    next_cap = candidate_next
                    continue

                # 0 graspable caps visible outside bridge band -> clear-FOV verification park at (0,0)
                self._emit_hud("PARK_FOR_SCAN", {})
                self._uart_write(bytes([CMD_PARK_FOR_SCAN]))
                if hb_sup is not None:
                    hb_sup.refresh_liveness(MAX_SINGLE_CAP_S)
                park_res = self._await_opcode_with_heartbeat(
                    CMD_AWAIT_NEXT, timeout_s=MAX_SINGLE_CAP_S, clock=clock, sleep_fn=sleep_fn
                )
                if park_res != "OK":
                    self._emit_hud(
                        "LINK_LOST" if park_res == "LINK_LOST" else "FAULT",
                        {"reason": f"PARK {park_res}"},
                    )
                    return _make_result(park_res)

                self._emit_hud("AWAIT_NEXT", {"at_xy": (0.0, 0.0)})
                verify_frame, verify_caps = _capture_and_detect_timed(occluded_y_mm=None)
                if hb_sup is not None and hb_sup.vision_stalled:
                    self._emit_hud("FAULT", {"reason": "VISION STALL WATCHDOG"})
                    return _make_result("VISION_STALL")
                if hb_sup is not None and hb_sup.link_lost:
                    self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
                    return _make_result("LINK_LOST")
                if not retry_evaluated:
                    self._update_retry_state(
                        last_target, verify_caps, retry_records, quarantined_zones, occluded_y_mm=None
                    )
                self._emit_hud(
                    "AWAIT_NEXT",
                    {
                        "at_xy": (0.0, 0.0),
                        "caps": verify_caps,
                        "scans": scans,
                        "quarantined": quarantined_zones,
                        "cam_frame": verify_frame,
                    },
                )
                revealed = self.select_next_cap(
                    verify_caps, (0.0, 0.0), retry_records, quarantined_zones
                )
                if revealed is not None:
                    next_cap = revealed
                    continue

                # Confirmed empty (or only quarantined/out-of-bounds caps remain) -> finish cleanly
                _stop_hb()
                self._emit_hud("FINISH_SESSION", {})
                self._uart_write(bytes([CMD_FINISH_SESSION]))
                done_res = self._await_opcode_with_heartbeat(
                    CMD_BATCH_COMPLETE, timeout_s=MAX_SINGLE_CAP_S, clock=clock, sleep_fn=sleep_fn
                )
                final_status = "COMPLETE" if done_res == "OK" else done_res
                self._emit_hud(
                    "SESSION_COMPLETE" if final_status == "COMPLETE" else (
                        "LINK_LOST" if final_status == "LINK_LOST" else "FAULT"
                    ),
                    {"caps": verify_caps, "picked": picked, "scans": scans, "reason": final_status},
                )
                return _make_result(final_status)

            # Reached hard cycle limit -> park safely
            _stop_hb()
            self._emit_hud("FINISH_SESSION", {})
            self._uart_write(bytes([CMD_FINISH_SESSION]))
            self._await_opcode_with_heartbeat(
                CMD_BATCH_COMPLETE, timeout_s=MAX_SINGLE_CAP_S, clock=clock, sleep_fn=sleep_fn
            )
            self._emit_hud("SESSION_COMPLETE", {"picked": picked, "scans": scans})
            return _make_result("MAX_CYCLES")
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] USB-TTL link dropped mid-session: {exc}", file=sys.stderr)
            self._close_serial()
            self._emit_hud("LINK_LOST", {"reason": "USB-TTL DISCONNECT"})
            return _make_result("LINK_LOST")
        finally:
            _stop_hb()

    def transmit_batch_and_supervise(
        self,
        ordered_caps: list,
        clock=time.monotonic,
        sleep_fn=time.sleep,
    ) -> str:
        """
        Legacy open-loop batch transmitter (retained for offline tools & protocol tests).
        Transmits a CRC16-verified batch and maintains 250 ms heartbeat pings
        for the entire batch duration.

        Returns one of: "COMPLETE", "NACK", "FAULT", "TIMEOUT", "LINK_LOST".
        """
        if not ordered_caps or self.uart is None:
            return "NACK"
        packet = self.pack_batch_packet(ordered_caps)

        try:
            ack_received = False
            for _ in range(3):
                self.uart.reset_input_buffer()
                self.write_paced_uart(packet, sleep_fn=sleep_fn)
                ack = self.uart.read(1)
                if ack:
                    code = ack[0]
                    if code == CMD_BATCH_ACK:
                        ack_received = True
                        break
                    if code in (CMD_HARD_FAULT, CMD_RECOVERY_HALT, CMD_STATUS_FAULT):
                        return "FAULT"
                sleep_fn(0.05)

            if not ack_received:
                return "NACK"

            start_t = clock()
            last_progress_t = start_t
            max_total_s = len(ordered_caps) * PER_CAP_BUDGET_S + BATCH_OVERHEAD_S

            while True:
                self._uart_write(bytes([CMD_HEARTBEAT_PING]))
                sleep_fn(HEARTBEAT_INTERVAL_S)

                while self.uart is not None and self.uart.in_waiting > 0:
                    with self._uart_lock:
                        resp_b = self.uart.read(1) if self.uart is not None else b""
                    if not resp_b:
                        break
                    resp = resp_b[0]
                    if resp == CMD_CAP_PROGRESS:
                        last_progress_t = clock()
                    elif resp == CMD_BATCH_COMPLETE:
                        return "COMPLETE"
                    elif resp in (CMD_RECOVERY_HALT, CMD_HARD_FAULT, CMD_STATUS_FAULT):
                        return "FAULT"

                now = clock()
                if (now - last_progress_t > MAX_SINGLE_CAP_S) or (now - start_t > max_total_s):
                    print(
                        "[TIMEOUT] Mega stopped reporting progress or exceeded dynamic batch ceiling.",
                        file=sys.stderr,
                    )
                    return "TIMEOUT"
        except SERIAL_EXCEPTIONS as exc:
            print(f"[UART] USB-TTL link dropped during batch supervision: {exc}", file=sys.stderr)
            self._close_serial()
            return "LINK_LOST"


def main():
    parser = argparse.ArgumentParser(description="CapSorter V2 Raspberry Pi Zero 2 W Closed-Loop Vision Controller")
    parser.add_argument("--calib", help="Path to validated camera calibration .npz file")
    parser.add_argument("--camera-type", choices=("picamera2_imx219", "usb_v4l2"))
    parser.add_argument(
        "--serial-port", default=DEFAULT_SERIAL_PORT,
        help="Mega serial port or 'auto' (prefers /dev/capsorter_mega -> /dev/ttyUSB* -> /dev/ttyACM* -> /dev/serial0)",
    )
    parser.add_argument("--bridge-occlusion-mm", type=float, default=BRIDGE_OCCLUSION_HALF_MM)
    parser.add_argument("--jaw-axis", choices=("X", "Y"), default=GRIPPER_JAW_AXIS)
    parser.add_argument("--enable-lcd", action="store_true", help="Enable native 480x320 3.5-inch SPI LCD HUD")
    parser.add_argument("--fb-device", default="/dev/fb0", help="Framebuffer device for 3.5-inch SPI LCD (default: /dev/fb0)")
    parser.add_argument("--touch-device", default="auto", help="XPT2046 evdev input path or 'auto'")
    parser.add_argument("--touch-swap-xy", action="store_true", help="Swap XPT2046 X/Y touch axes")
    parser.add_argument("--touch-invert-x", action="store_true", help="Invert XPT2046 X touch axis")
    parser.add_argument("--touch-invert-y", action="store_true", help="Invert XPT2046 Y touch axis")
    args = parser.parse_args()

    hud = None
    if args.enable_lcd:
        from lcd_hud import CapSorterLCDHUD
        hud = CapSorterLCDHUD(
            fb_device=args.fb_device,
            touch_device=args.touch_device,
            touch_swap_xy=args.touch_swap_xy,
            touch_invert_x=args.touch_invert_x,
            touch_invert_y=args.touch_invert_y,
        )

    try:
        controller = PiZeroVisionController(
            calib_file=args.calib,
            serial_port=args.serial_port,
            camera_type=args.camera_type,
            init_hardware=True,
            bridge_occlusion_half_mm=args.bridge_occlusion_mm,
            jaw_axis=args.jaw_axis,
            state_callback=hud.update_state if hud is not None else None,
        )
    except CalibrationError as exc:
        print(f"[FAIL-CLOSED CALIBRATION ERROR] {exc}", file=sys.stderr)
        sys.exit(2)

    if hud is not None:
        hud.on_pause_toggle = lambda is_paused: setattr(controller, "paused", bool(is_paused))
        hud.on_rearm = controller.send_rearm_home
        hud.start()

    print(f"[V2] Using Mega serial link: {controller.resolved_serial_port} @ 115200 baud")
    print("[V2] Waiting for Arduino Mega CMD_STATUS_READY handshake...")
    try:
        while not controller.wait_for_mega_ready(timeout_s=5.0):
            if controller.uart is None:
                controller.reconnect_serial()
            print("[V2] Mega not READY (homing, fault latched, or USB-TTL offline); retrying...")
            time.sleep(1.0)
        print("[V2] Mega READY. Starting closed-loop bin-side re-imaging vision loop.")

        while True:
            if controller.paused:
                time.sleep(0.25)
                continue

            if controller.uart is None:
                controller.reconnect_serial()
                time.sleep(1.0)
                continue

            if not controller.wait_for_mega_ready(timeout_s=2.0):
                print("[V2] Mega unavailable or faulted; waiting for operator re-arm & READY...")
                time.sleep(1.0)
                continue

            result = controller.run_closed_loop_sort_session()
            if result["status"] == "LINK_LOST":
                print(
                    "[V2] USB-TTL link dropped mid-session; reopening serial port & waiting for operator re-arm...",
                    file=sys.stderr,
                )
                controller.reconnect_serial()
                time.sleep(1.0)
            elif result["status"] == "PAUSED":
                print(
                    f"[V2] Session paused cleanly at (0,0) after {result['picked']} cap(s). "
                    "Tap RESUME on LCD to continue."
                )
                time.sleep(0.5)
            elif result["status"] != "COMPLETE":
                print(
                    f"[V2] Session ended with status={result['status']} "
                    f"(picked={result['picked']}, scans={result['scans']}). "
                    "Inhibiting new scans until Mega is READY.",
                    file=sys.stderr,
                )
                time.sleep(1.0)
            elif result["picked"] > 0:
                print(
                    f"[V2] Session COMPLETE: picked={result['picked']}, scans={result['scans']}, "
                    f"quarantined={len(result['quarantined'])}."
                )
            time.sleep(0.5)
    finally:
        if hud is not None:
            hud.stop()


if __name__ == "__main__":
    main()

def compute_axis_move_time(distance_mm: float) -> float:
    """Exact trapezoidal/triangular profile duration matching Mega AccelStepper."""
    d = abs(float(distance_mm))
    if d <= 1e-6:
        return 0.0
    v = MEGA_MAX_SPEED_MM_S
    a = MEGA_ACCEL_MM_S2
    d_ramp = (v * v) / a
    if d >= d_ramp:
        return (d / v) + (v / a)
    return 2.0 * math.sqrt(d / a)


def compute_xy_move_time(dx_mm: float, dy_mm: float) -> float:
    return max(compute_axis_move_time(dx_mm), compute_axis_move_time(dy_mm))


def _smoothstep(u: float) -> float:
    u = min(1.0, max(0.0, float(u)))
    return u * u * (3.0 - 2.0 * u)


def bgr_to_rgb565_bytes(bgr: np.ndarray) -> bytes:
    """
    Packs a 480x320x3 BGR uint8 OpenCV image into little-endian RGB565 bytes
    for 16-bpp Linux framebuffer (/dev/fb0 or /dev/fb1) writes (307,200 B).
    """
    if bgr.shape[:2] != (LCD_HEIGHT, LCD_WIDTH):
        bgr = cv2.resize(bgr, (LCD_WIDTH, LCD_HEIGHT), interpolation=cv2.INTER_AREA)
    b = bgr[:, :, 0].astype(np.uint16)
    g = bgr[:, :, 1].astype(np.uint16)
    r = bgr[:, :, 2].astype(np.uint16)
    rgb565 = ((r & 0xF8) << 8) | ((g & 0xFC) << 3) | (b >> 3)
    return np.ascontiguousarray(rgb565, dtype="<u2").tobytes()


def bgr_to_bgra32_bytes(bgr: np.ndarray) -> bytes:
    """
    Packs a 480x320x3 BGR uint8 OpenCV image into little-endian XRGB8888/BGRA32 bytes
    for 32-bpp DRM fbdev emulation (/dev/fb0) writes (614,400 B).
    """
    if bgr.shape[:2] != (LCD_HEIGHT, LCD_WIDTH):
        bgr = cv2.resize(bgr, (LCD_WIDTH, LCD_HEIGHT), interpolation=cv2.INTER_AREA)
    bgra = cv2.cvtColor(bgr, cv2.COLOR_BGR2BGRA)
    return np.ascontiguousarray(bgra, dtype=np.uint8).tobytes()


def probe_framebuffer_info(fb_device: str) -> FramebufferInfo:
    """
    Queries true Linux fbdev resolution, bits-per-pixel, row stride (line_length),
    and RGB/BGR bitfield offsets via FBIOGET_VSCREENINFO / FBIOGET_FSCREENINFO,
    falling back gracefully to sysfs and packed 480x320 RGB565 defaults.
    """
    info = FramebufferInfo()
    if not fb_device:
        return info

    # 1. Preferred: direct Linux fbdev ioctl query
    if fcntl is not None and os.path.exists(fb_device):
        try:
            with open(fb_device, "rb") as fb:
                vbuf = bytearray(160)
                fcntl.ioctl(fb.fileno(), FBIOGET_VSCREENINFO, vbuf, True)
                xres, yres = struct.unpack_from("<II", vbuf, 0)
                bpp = struct.unpack_from("<I", vbuf, 24)[0]
                r_off, r_len, _ = struct.unpack_from("<III", vbuf, 36)
                g_off, g_len, _ = struct.unpack_from("<III", vbuf, 48)
                b_off, b_len, _ = struct.unpack_from("<III", vbuf, 60)

                fbuf = bytearray(80)
                fcntl.ioctl(fb.fileno(), FBIOGET_FSCREENINFO, fbuf, True)
                fix_fmt = "@16sLIIIIHHHI"
                line_len = struct.unpack_from(fix_fmt, fbuf, 0)[-1]

                if xres > 0 and yres > 0 and bpp in (16, 32):
                    min_stride = xres * (bpp // 8)
                    return FramebufferInfo(
                        width=int(xres),
                        height=int(yres),
                        bpp=int(bpp),
                        line_length=max(int(line_len), min_stride),
                        red_offset=int(r_off),
                        red_len=int(r_len) or (8 if bpp == 32 else 5),
                        green_offset=int(g_off),
                        green_len=int(g_len) or (8 if bpp == 32 else 6),
                        blue_offset=int(b_off),
                        blue_len=int(b_len) or (8 if bpp == 32 else 5),
                    )
        except (OSError, struct.error, ValueError):
            pass

    # 2. Secondary fallback: Linux sysfs attributes
    fb_name = os.path.basename(fb_device)
    sys_dir = f"/sys/class/graphics/{fb_name}"
    try:
        with open(os.path.join(sys_dir, "bits_per_pixel"), "r", encoding="utf-8") as fh:
            val = int(fh.read().strip())
            if val in (16, 32):
                info.bpp = val
                if val == 32:
                    info.red_offset, info.red_len = 16, 8
                    info.green_offset, info.green_len = 8, 8
                    info.blue_offset, info.blue_len = 0, 8
    except (OSError, ValueError):
        pass
    try:
        with open(os.path.join(sys_dir, "virtual_size"), "r", encoding="utf-8") as fh:
            w_s, h_s = fh.read().strip().split(",")
            w_i, h_i = int(w_s), int(h_s)
            if w_i > 0 and h_i > 0:
                info.width, info.height = w_i, h_i
    except (OSError, ValueError):
        pass
    min_stride = info.width * (info.bpp // 8)
    info.line_length = min_stride
    try:
        with open(os.path.join(sys_dir, "stride"), "r", encoding="utf-8") as fh:
            st_i = int(fh.read().strip())
            if st_i >= min_stride:
                info.line_length = st_i
    except (OSError, ValueError):
        pass
    return info


def pack_bgr_for_framebuffer(bgr: np.ndarray, fb_info: FramebufferInfo) -> bytes:
    """
    Resizes if needed, packs BGR uint8 pixels according to the framebuffer's exact
    bpp and red/green/blue bitfield offsets/lengths, and pads each scanline to
    fb_info.line_length bytes so padded DRM/SPI strides never skew or corrupt pixels.
    """
    w = int(fb_info.width)
    h = int(fb_info.height)
    if bgr.shape[:2] != (h, w):
        bgr = cv2.resize(bgr, (w, h), interpolation=cv2.INTER_AREA)

    b_u8 = bgr[:, :, 0]
    g_u8 = bgr[:, :, 1]
    r_u8 = bgr[:, :, 2]

    if fb_info.bpp == 32:
        bytes_per_px = 4
        r_shift = max(0, 8 - fb_info.red_len)
        g_shift = max(0, 8 - fb_info.green_len)
        b_shift = max(0, 8 - fb_info.blue_len)
        packed = (
            ((r_u8.astype(np.uint32) >> r_shift) << fb_info.red_offset)
            | ((g_u8.astype(np.uint32) >> g_shift) << fb_info.green_offset)
            | ((b_u8.astype(np.uint32) >> b_shift) << fb_info.blue_offset)
        )
        # Preserve opaque alpha byte in whichever 8-bit lane is unused (typically bit 24)
        used_offsets = {fb_info.red_offset, fb_info.green_offset, fb_info.blue_offset}
        for alpha_off in (24, 0):
            if alpha_off not in used_offsets:
                packed |= np.uint32(0xFF) << alpha_off
                break
        row_bytes_arr = np.ascontiguousarray(packed, dtype="<u4").view(np.uint8).reshape(h, w * bytes_per_px)
    elif fb_info.bpp == 16:
        bytes_per_px = 2
        r_shift = max(0, 8 - fb_info.red_len)
        g_shift = max(0, 8 - fb_info.green_len)
        b_shift = max(0, 8 - fb_info.blue_len)
        packed = (
            ((r_u8.astype(np.uint16) >> r_shift) << fb_info.red_offset)
            | ((g_u8.astype(np.uint16) >> g_shift) << fb_info.green_offset)
            | ((b_u8.astype(np.uint16) >> b_shift) << fb_info.blue_offset)
        )
        row_bytes_arr = np.ascontiguousarray(packed, dtype="<u2").view(np.uint8).reshape(h, w * bytes_per_px)
    else:
        raise ValueError(f"Unsupported framebuffer bpp={fb_info.bpp}; expected 16 or 32.")

    row_width_bytes = w * bytes_per_px
    stride = max(int(fb_info.line_length), row_width_bytes)
    if stride > row_width_bytes:
        padded = np.zeros((h, stride), dtype=np.uint8)
        padded[:, :row_width_bytes] = row_bytes_arr
        return padded.tobytes()
    return row_bytes_arr.tobytes()


def hit_test_touch_button(x_px: int, y_px: int):
    """Returns button id ('pause', 'rearm', 'view') if (x_px, y_px) hits a button."""
    for name, (x0, y0, x1, y1) in TOUCH_BUTTONS.items():
        if x0 <= x_px <= x1 and y0 <= y_px <= y1:
            return name
    return None


class KinematicGantryPredictor:
    """
    Predicts continuous real-time gantry (X, Y), Z-state, and gripper state
    anchored to Mega's actual UART milestone opcodes (CMD_BATCH_ACK,
    CMD_SCAN_WINDOW_OPEN, CMD_CAP_PROGRESS, CMD_AWAIT_NEXT, CMD_BATCH_COMPLETE)
    so the 3.5" LCD animates smoothly with zero extra AVR serial overhead.
    """

    def __init__(self):
        self.x = 0.0
        self.y = 0.0
        self.z_state = "RAISED"       # RAISED | LOWER_PICK | LOWER_BIN
        self.gripper_state = "OPEN"   # OPEN | CLOSED
        self.held_color = None
        self.phase = "IDLE"
        self.occluded_y_mm = None
        self.scan_flash_until = 0.0

        self._seg_start_t = 0.0
        self._seg_dur = 0.0
        self._start_xy = (0.0, 0.0)
        self._target_xy = (0.0, 0.0)
        self._pick_xy = None
        self._bin_xy = None
        self._pick_color = None
        self._t_to_cap = 0.0
        self._t_to_bin = 0.0

    def start_pick_cycle(self, target_x: float, target_y: float, color: int, now: float):
        """Anchored when Mega acknowledges CMD_PICK_SINGLE (0x5B -> 0xA1)."""
        self.update(now)
        bin_y = BIN_Y_BY_COLOR.get(color, 130.0)
        self._start_xy = (self.x, self.y)
        self._pick_xy = (float(target_x), float(target_y))
        self._bin_xy = (355.0, bin_y)
        self._pick_color = color
        self._t_to_cap = max(0.15, compute_xy_move_time(self._pick_xy[0] - self.x, self._pick_xy[1] - self.y))
        self._t_to_bin = max(0.15, compute_xy_move_time(self._bin_xy[0] - self._pick_xy[0], self._bin_xy[1] - self._pick_xy[1]))
        self._seg_start_t = now
        self.phase = "PICK_CYCLE"
        self.occluded_y_mm = None

    def mark_bin_scan_window(self, bin_y: float, now: float):
        """Anchored on Mega CMD_SCAN_WINDOW_OPEN (0xA5): stationary at bin, dropping cap."""
        self.x = 355.0
        self.y = float(bin_y)
        self.z_state = "LOWER_BIN"
        self.gripper_state = "CLOSED"
        self.held_color = self._pick_color
        self.phase = "BIN_DROP"
        self.occluded_y_mm = float(bin_y)
        self.scan_flash_until = now + 0.45
        self._seg_start_t = now

    def mark_await_next(self, at_xy: tuple, now: float):
        """Anchored on Mega CMD_AWAIT_NEXT (0xA6)."""
        self.x, self.y = float(at_xy[0]), float(at_xy[1])
        self.z_state = "RAISED"
        self.gripper_state = "OPEN"
        self.held_color = None
        self.phase = "AWAIT_NEXT"
        self.occluded_y_mm = None

    def start_park(self, now: float, for_scan: bool = True):
        """Anchored on CMD_PARK_FOR_SCAN (0xB5) or CMD_FINISH_SESSION (0xB6)."""
        self.update(now)
        self._start_xy = (self.x, self.y)
        self._target_xy = (0.0, 0.0)
        self._seg_dur = max(0.15, compute_xy_move_time(self.x, self.y))
        self._seg_start_t = now
        self.z_state = "RAISED"
        self.gripper_state = "OPEN"
        self.held_color = None
        self.occluded_y_mm = None
        self.phase = "PARKING_SCAN" if for_scan else "PARKING_HOME"

    def mark_idle(self, now: float):
        self.x, self.y = 0.0, 0.0
        self.z_state = "RAISED"
        self.gripper_state = "OPEN"
        self.held_color = None
        self.occluded_y_mm = None
        self.phase = "IDLE"

    def mark_fault(self, label: str, now: float):
        self.update(now)
        self.phase = label
        self.occluded_y_mm = None

    def update(self, now: float) -> dict:
        dt = max(0.0, now - self._seg_start_t)

        if self.phase == "PICK_CYCLE" and self._pick_xy is not None:
            t1 = self._t_to_cap
            t2 = t1 + PICK_LOWER_S
            t3 = t2 + PICK_GRIP_S
            t4 = t3 + PICK_LIFT_S
            t5 = t4 + self._t_to_bin

            if dt < t1:
                u = _smoothstep(dt / t1)
                self.x = self._start_xy[0] + (self._pick_xy[0] - self._start_xy[0]) * u
                self.y = self._start_xy[1] + (self._pick_xy[1] - self._start_xy[1]) * u
                self.z_state = "RAISED"
                self.gripper_state = "OPEN"
                self.held_color = None
            elif dt < t2:
                self.x, self.y = self._pick_xy
                self.z_state = "LOWER_PICK"
                self.gripper_state = "OPEN"
                self.held_color = None
            elif dt < t3:
                self.x, self.y = self._pick_xy
                self.z_state = "LOWER_PICK"
                self.gripper_state = "CLOSED"
                self.held_color = self._pick_color
            elif dt < t4:
                self.x, self.y = self._pick_xy
                self.z_state = "RAISED"
                self.gripper_state = "CLOSED"
                self.held_color = self._pick_color
            elif dt < t5:
                u = _smoothstep((dt - t4) / self._t_to_bin)
                self.x = self._pick_xy[0] + (self._bin_xy[0] - self._pick_xy[0]) * u
                self.y = self._pick_xy[1] + (self._bin_xy[1] - self._pick_xy[1]) * u
                self.z_state = "RAISED"
                self.gripper_state = "CLOSED"
                self.held_color = self._pick_color
            else:
                self.x, self.y = self._bin_xy
                self.z_state = "RAISED"
                self.gripper_state = "CLOSED"
                self.held_color = self._pick_color

        elif self.phase == "BIN_DROP":
            if dt < BIN_LOWER_S:
                self.z_state = "LOWER_BIN"
                self.gripper_state = "CLOSED"
                self.held_color = self._pick_color
            elif dt < BIN_LOWER_S + BIN_RELEASE_S:
                self.z_state = "LOWER_BIN"
                self.gripper_state = "OPEN"
                self.held_color = None
            else:
                self.z_state = "RAISED"
                self.gripper_state = "OPEN"
                self.held_color = None

        elif self.phase in ("PARKING_SCAN", "PARKING_HOME"):
            u = _smoothstep(dt / max(0.05, self._seg_dur))
            self.x = self._start_xy[0] + (self._target_xy[0] - self._start_xy[0]) * u
            self.y = self._start_xy[1] + (self._target_xy[1] - self._start_xy[1]) * u

        return {
            "x": self.x,
            "y": self.y,
            "z": self.z_state,
            "gripper": self.gripper_state,
            "held_color": self.held_color,
            "phase": self.phase,
            "occluded_y_mm": self.occluded_y_mm,
            "scan_flash": now < self.scan_flash_until,
        }


class CapSorterLCDHUD:
    """
    Non-blocking 480x320 framebuffer HUD & resistive-touch operator interface.
    Safe for read-only OverlayFS (zero disk writes) and 512 MB Pi Zero 2 W RAM.
    """

    def __init__(
        self,
        fb_device: str = "/dev/fb0",
        touch_device: str = "auto",
        fps: float = 15.0,
        on_pause_toggle=None,
        on_rearm=None,
        touch_cal: tuple = (200, 3900, 200, 3900),
        touch_swap_xy: bool = False,
        touch_invert_x: bool = False,
        touch_invert_y: bool = False,
    ):
        self.fb_device = fb_device
        self.touch_device = touch_device
        self.frame_interval_s = 1.0 / max(1.0, float(fps))
        self.on_pause_toggle = on_pause_toggle
        self.on_rearm = on_rearm
        self.touch_cal = tuple(float(v) for v in touch_cal)
        self.touch_swap_xy = bool(touch_swap_xy)
        self.touch_invert_x = bool(touch_invert_x)
        self.touch_invert_y = bool(touch_invert_y)
        self._fb_info = probe_framebuffer_info(self.fb_device)
        self._fb_bpp = self._fb_info.bpp

        self._lock = threading.Lock()
        self._stop_evt = threading.Event()
        self._render_thread = None
        self._touch_thread = None

        self.predictor = KinematicGantryPredictor()
        self.view_mode = "MAP"  # "MAP" | "CAM"
        self.paused = False
        self.state = {
            "controller_state": "BOOTING",
            "link_status": "WAIT_MEGA",
            "serial_port": "auto",
            "caps": [],
            "active_target": None,
            "quarantined": [],
            "bin_counts": {COLOR_RED: 0, COLOR_YELLOW: 0, COLOR_GREEN: 0, COLOR_BLUE: 0},
            "scans": 0,
            "picked": 0,
            "fault_banner": "",
            "cam_thumb": None,
        }

    def update_state(self, event: str, payload: dict = None, now: float = None):
        """Thread-safe update called from PiZeroVisionController milestones."""
        payload = payload or {}
        t = time.monotonic() if now is None else float(now)

        with self._lock:
            if "serial_port" in payload:
                self.state["serial_port"] = str(payload["serial_port"])
            if "link_status" in payload:
                self.state["link_status"] = str(payload["link_status"])
            if "caps" in payload:
                self.state["caps"] = [dict(c) for c in payload["caps"]]
            if "quarantined" in payload:
                self.state["quarantined"] = [dict(q) for q in payload["quarantined"]]
            if "scans" in payload:
                self.state["scans"] = int(payload["scans"])
            if "picked" in payload:
                self.state["picked"] = int(payload["picked"])
            if "cam_frame" in payload and payload["cam_frame"] is not None:
                self.state["cam_thumb"] = cv2.resize(
                    payload["cam_frame"], (BOARD_PX, BOARD_PX), interpolation=cv2.INTER_AREA
                )

            if event == "READY":
                self.state["controller_state"] = "READY"
                self.state["link_status"] = "ONLINE"
                self.state["fault_banner"] = ""
                self.state["active_target"] = None
                self.predictor.mark_idle(t)
            elif event == "SCAN_INITIAL":
                self.state["controller_state"] = "SCANNING"
                self.predictor.scan_flash_until = t + 0.35
            elif event == "TARGET_DISPATCHED":
                tgt = payload.get("target")
                self.state["active_target"] = dict(tgt) if tgt else None
                self.state["controller_state"] = "PICKING"
                if tgt:
                    self.predictor.start_pick_cycle(tgt["boardX_mm"], tgt["boardY_mm"], tgt["color"], t)
            elif event == "SCAN_WINDOW_OPEN":
                bin_y = float(payload.get("bin_y", 130.0))
                self.state["controller_state"] = "BIN_SCAN"
                self.predictor.mark_bin_scan_window(bin_y, t)
            elif event == "CAP_SORTED":
                col = payload.get("color")
                if col in self.state["bin_counts"]:
                    self.state["bin_counts"][col] += 1
            elif event == "AWAIT_NEXT":
                at_xy = payload.get("at_xy", (self.predictor.x, self.predictor.y))
                self.predictor.mark_await_next(at_xy, t)
                self.state["controller_state"] = "AWAIT_NEXT"
            elif event == "PARK_FOR_SCAN":
                self.state["controller_state"] = "VERIFY_PARK"
                self.predictor.start_park(t, for_scan=True)
            elif event == "FINISH_SESSION":
                self.state["controller_state"] = "PARKING"
                self.state["active_target"] = None
                self.predictor.start_park(t, for_scan=False)
            elif event == "SESSION_COMPLETE":
                self.state["controller_state"] = "IDLE"
                self.state["active_target"] = None
                self.predictor.mark_idle(t)
            elif event == "PAUSED":
                self.state["controller_state"] = "PAUSED"
                self.state["active_target"] = None
                self.predictor.mark_idle(t)
            elif event == "REARMING":
                self.state["controller_state"] = "HOMING"
                self.state["fault_banner"] = ""
            elif event in ("FAULT", "LINK_LOST", "TIMEOUT"):
                self.state["controller_state"] = event
                self.state["link_status"] = "OFFLINE" if event == "LINK_LOST" else "FAULT"
                self.state["fault_banner"] = payload.get("reason", event)
                self.predictor.mark_fault(event, t)

    def handle_touch_px(self, x_px: int, y_px: int):
        """Dispatches a calibrated (x_px, y_px) tap to HUD buttons."""
        btn = hit_test_touch_button(x_px, y_px)
        if btn == "pause":
            with self._lock:
                self.paused = not self.paused
                paused_now = self.paused
            if self.on_pause_toggle is not None:
                self.on_pause_toggle(paused_now)
        elif btn == "rearm":
            if self.on_rearm is not None:
                self.on_rearm()
        elif btn == "view":
            with self._lock:
                self.view_mode = "CAM" if self.view_mode == "MAP" else "MAP"
        return btn

    def render_frame_bgr(self, now: float = None) -> np.ndarray:
        """Renders a complete 480x320 BGR frame (usable headless in tests)."""
        t = time.monotonic() if now is None else float(now)
        img = np.full((LCD_HEIGHT, LCD_WIDTH, 3), COL_BG, dtype=np.uint8)

        with self._lock:
            pose = self.predictor.update(t)
            st = {
                "controller_state": self.state["controller_state"],
                "link_status": self.state["link_status"],
                "serial_port": self.state["serial_port"],

    def _detect_fb_bpp(self) -> int:
        self._fb_info = probe_framebuffer_info(self.fb_device)
        return self._fb_info.bpp

    def _blit_framebuffer(self, frame_bgr: np.ndarray):
        payload = pack_bgr_for_framebuffer(frame_bgr, self._fb_info)
        try:
            with open(self.fb_device, "r+b", buffering=0) as fb:
                fb.seek(0)
                fb.write(payload)
        except OSError:
            with open(self.fb_device, "wb") as fb:
                fb.write(payload)

    def _render_loop(self):
        while not self._stop_evt.is_set():
            t0 = time.monotonic()
            try:
                frame = self.render_frame_bgr(now=t0)
                if self.fb_device and os.path.exists(self.fb_device):
                    self._blit_framebuffer(frame)
            except OSError:
                pass
            elapsed = time.monotonic() - t0
            self._stop_evt.wait(max(0.01, self.frame_interval_s - elapsed))

    def _find_touch_input_device(self):
        if self.touch_device and self.touch_device != "auto":
            return self.touch_device
        for path in sorted(glob.glob("/sys/class/input/event*/device/name")):
            try:
                with open(path, "r", encoding="utf-8") as fh:
                    name = fh.read().strip().lower()
                if any(tok in name for tok in ("ads7846", "xpt2046", "touch")):
                    ev_name = path.split("/")[4]
                    return f"/dev/input/{ev_name}"
            except OSError:
                continue
        return None

    def _touch_loop(self):
        """
        Reads Linux evdev input_event structs directly from XPT2046 (/dev/input/event*)
        with zero external dependencies (EV_ABS=3, EV_KEY=1, BTN_TOUCH=330).
        """
        dev_path = self._find_touch_input_device()
        if not dev_path or not os.path.exists(dev_path):
            return
        # 64-bit Linux struct input_event: (timeval sec:q, usec:q, type:H, code:H, value:i) = 24B
        ev_fmt = "llHHi"
        ev_size = struct.calcsize(ev_fmt)
        raw_x, raw_y = 2048, 2048
        try:
            fd = os.open(dev_path, os.O_RDONLY | os.O_NONBLOCK)
        except OSError:
            return
        try:
            while not self._stop_evt.is_set():
                rlist, _, _ = select.select([fd], [], [], 0.2)
                if not rlist:
                    continue
                try:
                    data = os.read(fd, ev_size * 16)
                except BlockingIOError:
                    continue
                except OSError:
                    break
                for off in range(0, len(data) - (len(data) % ev_size), ev_size):
                    _, _, ev_type, code, value = struct.unpack(ev_fmt, data[off:off + ev_size])
                    if ev_type == 3:  # EV_ABS
                        if code == 0:    # ABS_X
                            raw_x = value
                        elif code == 1:  # ABS_Y
                            raw_y = value
                    elif ev_type == 1 and code == 330 and value == 0:  # BTN_TOUCH release
                        ax, ay = (raw_y, raw_x) if self.touch_swap_xy else (raw_x, raw_y)
                        x_min, x_max, y_min, y_max = self.touch_cal
                        nx = (ax - x_min) / max(1.0, (x_max - x_min))
                        ny = (ay - y_min) / max(1.0, (y_max - y_min))
                        if self.touch_invert_x:
                            nx = 1.0 - nx
                        if self.touch_invert_y:
                            ny = 1.0 - ny
                        px = int(min(LCD_WIDTH - 1, max(0, nx * LCD_WIDTH)))
                        py = int(min(LCD_HEIGHT - 1, max(0, ny * LCD_HEIGHT)))
                        self.handle_touch_px(px, py)
        finally:
            os.close(fd)

    def start(self):
        if self._render_thread is not None:
            return
        self._stop_evt.clear()
        self._render_thread = threading.Thread(target=self._render_loop, name="lcd_hud_render", daemon=True)
        self._render_thread.start()
        self._touch_thread = threading.Thread(target=self._touch_loop, name="lcd_hud_touch", daemon=True)
        self._touch_thread.start()

    def stop(self):
        self._stop_evt.set()
        if self._render_thread is not None:
            self._render_thread.join(timeout=1.0)
            self._render_thread = None
        if self._touch_thread is not None:
            self._touch_thread.join(timeout=1.0)
            self._touch_thread = None

def calibrate_intrinsics_from_checkerboards(
    image_paths: list,
    pattern_size: tuple = (9, 6),
    square_size_mm: float = 25.0,
    lens_model: str = "fisheye",
    min_images: int = 8,
    max_reproj_err: float = 1.0,
):
    """
    Computes camera intrinsic matrix K and distortion coefficients D from
    real checkerboard images using either OpenCV's fisheye or pinhole model.
    Returns (K, D, image_size, rms_error_px).
    """
    if lens_model not in VALID_LENS_MODELS:
        raise ValueError(f"Unsupported lens_model '{lens_model}'; expected one of {VALID_LENS_MODELS}")
    if not image_paths:
        raise ValueError("No checkerboard images provided for intrinsic calibration.")

    cols, rows = int(pattern_size[0]), int(pattern_size[1])
    objp = np.zeros((1, cols * rows, 3), np.float32)
    objp[0, :, :2] = np.mgrid[0:cols, 0:rows].T.reshape(-1, 2) * float(square_size_mm)

    objpoints = []
    imgpoints = []
    image_size = None
    subpix_criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 1e-3)

    for path in sorted(image_paths):
        img = cv2.imread(path)
        if img is None:
            continue
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        h, w = gray.shape[:2]
        if image_size is None:
            image_size = (w, h)
        elif image_size != (w, h):
            raise ValueError(
                f"Inconsistent image resolution in {path}: got {(w, h)}, expected {image_size}"
            )

        found, corners = cv2.findChessboardCorners(
            gray, (cols, rows),
            cv2.CALIB_CB_ADAPTIVE_THRESH + cv2.CALIB_CB_FAST_CHECK + cv2.CALIB_CB_NORMALIZE_IMAGE,
        )
        if not found:
            continue

        refined = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1), subpix_criteria)
        if lens_model == "fisheye":
            objpoints.append(objp.astype(np.float64))
            imgpoints.append(refined.reshape(1, -1, 2).astype(np.float64))
        else:
            objpoints.append(objp.reshape(-1, 3).astype(np.float32))
            imgpoints.append(refined.astype(np.float32))

    if len(objpoints) < min_images:
        raise RuntimeError(
            f"Only {len(objpoints)} valid checkerboard images found; need at least {min_images}."
        )

    if lens_model == "fisheye":
        K = np.zeros((3, 3), dtype=np.float64)
        D = np.zeros((4, 1), dtype=np.float64)
        rvecs = [np.zeros((1, 1, 3), dtype=np.float64) for _ in objpoints]
        tvecs = [np.zeros((1, 1, 3), dtype=np.float64) for _ in objpoints]
        flags = (
            cv2.fisheye.CALIB_RECOMPUTE_EXTRINSIC
            + cv2.fisheye.CALIB_FIX_SKEW
        )
        rms, K, D, _, _ = cv2.fisheye.calibrate(
            objpoints, imgpoints, image_size, K, D, rvecs, tvecs,
            flags, (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 100, 1e-6),
        )
        D = np.asarray(D, dtype=np.float64).reshape((4, 1))
    else:
        rms, K, D, _, _ = cv2.calibrateCamera(
            objpoints, imgpoints, image_size, None, None
        )
        K = np.asarray(K, dtype=np.float64).reshape((3, 3))
        D = np.asarray(D, dtype=np.float64).reshape((-1, 1))

    if not np.isfinite(rms) or rms > max_reproj_err:
        raise RuntimeError(
            f"Intrinsic calibration RMS reprojection error {rms:.4f} px exceeds limit {max_reproj_err:.4f} px."
        )

    return K, D, image_size, float(rms)

    rectified_pixel_corners: np.ndarray,

    image_size: tuple = None,
    check_points_px: np.ndarray = None,
    check_points_mm: np.ndarray = None,
    max_check_err_mm: float = 2.5,
) -> np.ndarray:
    """
    Computes 3x3 planar homography matrix H mapping rectified image pixels
    (u, v) to physical sorting board coordinates (X_mm, Y_mm) after validating
    strict quadrilateral geometry (image bounds, convexity, clockwise winding,
    minimum area, side ratios, interior angles, TL->TR->BR->BL orientation),
    corner round-trip accuracy, and optional interior check-point accuracy.
    """
    rect_pts = np.asarray(rectified_pixel_corners, dtype=np.float32).reshape((4, 2))
    if not np.all(np.isfinite(rect_pts)):
        raise ValueError("Rectified fiducial pixel corners contain non-finite values.")

    # 1. Image bounds check (if image dimensions are known)
    if image_size is not None:
        img_w, img_h = float(image_size[0]), float(image_size[1])
        if img_w <= 0 or img_h <= 0:
            raise ValueError(f"Invalid image_size={image_size}")
        if (
            np.any(rect_pts[:, 0] < 0.0)
            or np.any(rect_pts[:, 0] >= img_w)
            or np.any(rect_pts[:, 1] < 0.0)
            or np.any(rect_pts[:, 1] >= img_h)
        ):
            raise ValueError(
                f"Fiducial corners fall outside image bounds {image_size}: {rect_pts.tolist()}"
            )

    # 2. Edge lengths, strict convexity, and clockwise winding (in image coords: +u right, +v down)
    edges = np.roll(rect_pts, -1, axis=0) - rect_pts
    edge_lens = np.linalg.norm(edges, axis=1)
    if float(np.min(edge_lens)) < 40.0:
        raise ValueError(
            f"Degenerate fiducial quadrilateral: shortest edge is {float(np.min(edge_lens)):.1f} px (<40 px)."
        )
    horiz_ratio = float(edge_lens[0] / edge_lens[2])
    vert_ratio = float(edge_lens[1] / edge_lens[3])
    if not (0.4 <= horiz_ratio <= 2.5 and 0.4 <= vert_ratio <= 2.5):
        raise ValueError(
            f"Fiducial quadrilateral has extreme perspective/edge-length distortion "
            f"(top/bottom={horiz_ratio:.2f}, right/left={vert_ratio:.2f})."
        )

    cross_z = []
    for i in range(4):
        e1 = edges[i]
        e2 = edges[(i + 1) % 4]
        cross_z.append(float(e1[0] * e2[1] - e1[1] * e2[0]))

    if not cv2.isContourConvex(rect_pts) or any(c == 0.0 for c in cross_z):
        raise ValueError(
            "Fiducial quadrilateral is non-convex or self-intersecting (bow-tie/crossed clicks)."
        )
    if any(c < 0.0 for c in cross_z):
        if all(c < 0.0 for c in cross_z):
            raise ValueError(
                "Fiducial corners have counter-clockwise/mirrored winding; expected clockwise TL->TR->BR->BL."
            )
        raise ValueError(
            "Fiducial quadrilateral is concave or self-intersecting (bow-tie/crossed clicks)."
        )

    # 3. Signed area & interior angle sanity (reject slivers / near-collinear quads)
    u = rect_pts[:, 0].astype(np.float64)
    v = rect_pts[:, 1].astype(np.float64)
    area_px2 = 0.5 * float(np.sum(u * np.roll(v, -1) - np.roll(u, -1) * v))
    min_area = 2500.0
    if image_size is not None:
        min_area = max(min_area, 0.05 * float(image_size[0]) * float(image_size[1]))
    if area_px2 < min_area:
        raise ValueError(
            f"Fiducial quadrilateral area {area_px2:.1f} px^2 is too small (min {min_area:.1f} px^2)."
        )

    for i in range(4):
        v_prev = rect_pts[(i - 1) % 4] - rect_pts[i]
        v_next = rect_pts[(i + 1) % 4] - rect_pts[i]
        cos_ang = float(np.dot(v_prev, v_next) / (np.linalg.norm(v_prev) * np.linalg.norm(v_next)))
        ang_deg = float(np.degrees(np.arccos(np.clip(cos_ang, -1.0, 1.0))))
        if not (40.0 <= ang_deg <= 140.0):
            raise ValueError(
                f"Fiducial corner #{i + 1} interior angle {ang_deg:.1f} deg outside [40, 140] deg."
            )

    # 4. Spatial TL/TR/BR/BL ordering consistency (rejects 90/180/270-degree rotated corner sequences)
    v_top_mid = 0.5 * (v[0] + v[1])
    v_bot_mid = 0.5 * (v[2] + v[3])
    u_left_mid = 0.5 * (u[0] + u[3])
    u_right_mid = 0.5 * (u[1] + u[2])
    if not (
        v_top_mid < v_bot_mid - 10.0
        and u_left_mid < u_right_mid - 10.0
        and u[0] < u[1]
        and u[3] < u[2]
        and v[0] < v[3]
        and v[1] < v[2]
    ):
        raise ValueError(
            "Fiducial corner order is rotated or inconsistent; expected TL -> TR -> BR -> BL."
        )

    H, _ = cv2.findHomography(rect_pts, BOARD_CORNERS_MM, method=0)
    if H is None or not np.all(np.isfinite(H)) or abs(np.linalg.det(H)) < 1e-12:
        raise ValueError("Degenerate fiducial corners produced a singular homography matrix.")

    H = H.astype(np.float64)
    mapped = cv2.perspectiveTransform(rect_pts.reshape(1, 4, 2), H).reshape(4, 2)
    max_err = float(np.max(np.linalg.norm(mapped - BOARD_CORNERS_MM, axis=1)))
    if max_err > max_corner_err_mm:
        raise RuntimeError(
            f"Homography corner mapping error {max_err:.4f} mm exceeds limit {max_corner_err_mm:.4f} mm."
        )

    # 5. Optional independent interior check-point verification (e.g., board center or test grid)
    if check_points_px is not None or check_points_mm is not None:
        if check_points_px is None or check_points_mm is None:
            raise ValueError("Provide both check_points_px and check_points_mm together.")
        chk_px = np.asarray(check_points_px, dtype=np.float32).reshape((-1, 2))
        chk_mm = np.asarray(check_points_mm, dtype=np.float64).reshape((-1, 2))
        if chk_px.shape != chk_mm.shape or chk_px.shape[0] == 0:
            raise ValueError("check_points_px and check_points_mm must be non-empty Nx2 arrays of matching shape.")
        if not (np.all(np.isfinite(chk_px)) and np.all(np.isfinite(chk_mm))):
            raise ValueError("Interior check points contain non-finite values.")
        mapped_chk = cv2.perspectiveTransform(chk_px.reshape(1, -1, 2), H).reshape(-1, 2)
        max_chk_err = float(np.max(np.linalg.norm(mapped_chk - chk_mm, axis=1)))
        if max_chk_err > max_check_err_mm:
            raise RuntimeError(
                f"Interior check-point mapping error {max_chk_err:.3f} mm exceeds limit {max_check_err_mm:.3f} mm."
            )

    return H


def save_validated_calibration(
    out_path: str,
    K: np.ndarray,
    D: np.ndarray,
    H: np.ndarray,
    camera_type: str,
    lens_model: str,
    image_size: tuple,
    reprojection_error_px: float,
    camera_height_mm: float = 0.0,
    cap_height_mm: float = 13.0,
):
    if camera_type not in VALID_CAMERA_TYPES:
        raise ValueError(f"Unsupported camera_type '{camera_type}'")
    if lens_model not in VALID_LENS_MODELS:
        raise ValueError(f"Unsupported lens_model '{lens_model}'")

    out_dir = os.path.dirname(out_path)
    if out_dir:
        os.makedirs(out_dir, exist_ok=True)

    timestamp = datetime.datetime.now(datetime.timezone.utc).isoformat()
    np.savez(
        out_path,
        K=np.asarray(K, dtype=np.float64).reshape((3, 3)),
        D=np.asarray(D, dtype=np.float64).reshape((-1, 1)),
        H=np.asarray(H, dtype=np.float64).reshape((3, 3)),
        camera_type=np.array(camera_type),
        lens_model=np.array(lens_model),
        image_size=np.array([int(image_size[0]), int(image_size[1])], dtype=np.int32),
        reprojection_error_px=np.array(float(reprojection_error_px), dtype=np.float64),
        camera_height_mm=np.array(float(camera_height_mm), dtype=np.float64),
        cap_height_mm=np.array(float(cap_height_mm), dtype=np.float64),
        calibrated=np.array(True, dtype=bool),
        calibrated_utc=np.array(timestamp),
    )
    print(
        f"[OK] Saved validated calibration ({camera_type}, {lens_model}, "
        f"{image_size[0]}x{image_size[1]}, RMS={reprojection_error_px:.4f} px, "
        f"H_cam={camera_height_mm:.1f} mm, h_cap={cap_height_mm:.1f} mm) -> {out_path}"
    )

def _parse_points_list_arg(points_str: str) -> np.ndarray:
    pairs = [p.strip() for p in points_str.split(";") if p.strip()]
    if not pairs:
        raise ValueError("Expected one or more semicolon-separated 'x,y' point pairs.")
    pts = []
    for p in pairs:
        x_str, y_str = p.split(",")
        pts.append([float(x_str.strip()), float(y_str.strip())])
    return np.array(pts, dtype=np.float32)


def _parse_corners_arg(corners_str: str) -> np.ndarray:
    pts = _parse_points_list_arg(corners_str)
    if pts.shape != (4, 2):
        raise ValueError("Expected 4 semicolon-separated 'u,v' corners (TL;TR;BR;BL).")
    return pts

#endif
}

bool isValidSingleTarget(const CapTarget &cap) {
  if (!isfinite(cap.boardX_mm) || !isfinite(cap.boardY_mm)) return false;
  if (cap.boardX_mm < SAFE_PICK_MIN_X_MM || cap.boardX_mm > SAFE_PICK_MAX_X_MM) return false;
  if (cap.boardY_mm < SAFE_PICK_MIN_Y_MM || cap.boardY_mm > SAFE_PICK_MAX_Y_MM) return false;
  float machX = cap.boardX_mm + TOOL_OFFSET_X_MM;
  float machY = cap.boardY_mm + TOOL_OFFSET_Y_MM;
  if (machX < 0.0f || machX > MAX_TRAVEL_X_MM) return false;
  if (machY < 0.0f || machY > MAX_TRAVEL_Y_MM) return false;
  if (cap.targetBinId < 1 || cap.targetBinId > 4) return false;
  return true;
}

// Raw homed machine-space move (used for (0,0) clear-FOV/home/failsafe parking and bin poses)
void moveMachineToMm(float machX_mm, float machY_mm) {
  float targetX = constrain(machX_mm, 0.0f, MAX_TRAVEL_X_MM);
  float targetY = constrain(machY_mm, 0.0f, MAX_TRAVEL_Y_MM);
  stepperX.moveTo(lroundf(targetX * STEPS_PER_MM_X));
  stepperY.moveTo(lroundf(targetY * STEPS_PER_MM_Y));
}

// Board-space move (applies bench-measured TOOL_OFFSET_X/Y_MM for cap pickup coordinates)
void moveBoardToMm(float boardX_mm, float boardY_mm) {
  moveMachineToMm(boardX_mm + TOOL_OFFSET_X_MM, boardY_mm + TOOL_OFFSET_Y_MM);
}

bool isGantryAtTarget() {
  return (stepperX.distanceToGo() == 0 && stepperY.distanceToGo() == 0);
}

void replyStatusQuery() {
  if (currentState == STATE_IDLE && isHomed && !commsFaultLatched && !isEstopActive()) {
    Serial1.write(CMD_STATUS_READY);
  } else if (currentState == STATE_FAILSAFE_HALT || currentState == STATE_HARD_FAULT) {
    Serial1.write(CMD_STATUS_FAULT);
  } else {
    Serial1.write(CMD_STATUS_BUSY);
  }
}

void serviceSerialDuringHoming() {
  // Drain Serial1 non-blockingly while homing so host queries get BUSY and FIFO never stalls
  while (Serial1.available() > 0) {
    uint8_t b = (uint8_t)Serial1.read();
    if (b == CMD_QUERY_STATUS) {
      Serial1.write(CMD_STATUS_BUSY);
    } else if (b == PROTOCOL_MAGIC_BYTE || b == PROTOCOL_SINGLE_MAGIC) {
      Serial1.write(CMD_BATCH_NACK);
    }
  }
}

void triggerHardFault(const __FlashStringHelper *reason) {
  stepperX.setSpeed(0.0f);
  stepperY.setSpeed(0.0f);
  stepperX.moveTo(stepperX.currentPosition());
  stepperY.moveTo(stepperY.currentPosition());
  digitalWrite(PIN_STEPPER_EN, HIGH); // Disable stepper coils immediately
  digitalWrite(PIN_SERVO_OE, HIGH);   // Disable PCA9685 PWM outputs (no commanded fault motion)
  closedLoopMode        = false;
  isHomed               = false;
  hasInFlightCap        = false;
  capPossessionVerified = false;
  batchTotal            = 0;
  currentIdx            = 0;
  currentState      = STATE_HARD_FAULT;
  Serial1.write(CMD_HARD_FAULT);
  Serial.print(F("[HARD_FAULT] "));
  Serial.println(reason);
}

bool waitServicedDelayMs(unsigned long durationMs) {
  unsigned long start = millis();
  while (millis() - start < durationMs) {
    if (isEstopActive()) {
      triggerHardFault(F("E-Stop active during servo settle"));
      return false;
    }
    serviceSerialDuringHoming();
  }
  return true;
}

void homeAxes() {
  currentState          = STATE_HOMING;
  closedLoopMode        = false;
  isHomed               = false;
  hasInFlightCap        = false;
  capPossessionVerified = false;
  commsFaultLatched     = false;
  limitFaultCount       = 0;
  estopFaultCount       = 0;
  limitOpenSinceMs      = 0;
  estopHighSinceMs      = 0;
  batchTotal            = 0;
  currentIdx            = 0;

  // 0. Refuse homing if hardwired E-stop auxiliary contact is active or Z overtravel is open
  if (isEstopActive()) {
    triggerHardFault(F("E-Stop active at homing start"));
    return;
  }
#if Z_LIMIT_IS_OVERTRAVEL
  if (isAxisLimitOpen(PIN_Z_HOME)) {
    triggerHardFault(F("Z overtravel switch open or broken wire at homing start"));
    return;
  }
#endif

  // 1. Retract Z-axis and open gripper cleanly before energizing XY steppers
  pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
  pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_OPEN);
  digitalWrite(PIN_SERVO_OE, LOW);    // Enable PCA9685 outputs after latching safe PWM
  if (!waitServicedDelayMs(450UL)) return;

  if (!isZSafeForXYMotion()) {
    triggerHardFault(zUnsafeReason());
    return;
  }

  digitalWrite(PIN_STEPPER_EN, LOW);  // Enable TMC2208 drivers (Active LOW)
  stepperX.setMinPulseWidth(2);
  stepperY.setMinPulseWidth(2);
  stepperX.setMaxSpeed(1000.0f);
  stepperY.setMaxSpeed(1000.0f);
  stepperX.setAcceleration(800.0f);
  stepperY.setAcceleration(800.0f);

  // 2. Broken NC Wire Pre-Check: Back off ONLY the axis whose switch already reads HIGH
  bool xInitiallyHigh = isAxisLimitOpen(PIN_X_HOME);
  bool yInitiallyHigh = isAxisLimitOpen(PIN_Y_HOME);
  if (xInitiallyHigh || yInitiallyHigh) {
    stepperX.setCurrentPosition(0);
    stepperY.setCurrentPosition(0);
    stepperX.moveTo(xInitiallyHigh ? lroundf(10.0f * STEPS_PER_MM_X) : 0L);
    stepperY.moveTo(yInitiallyHigh ? lroundf(10.0f * STEPS_PER_MM_Y) : 0L);
    unsigned long preStart = millis();
    while (!isGantryAtTarget()) {
      if (isEstopActive()) {
        triggerHardFault(F("E-Stop triggered during pre-homing backoff"));
        return;
      }
#if ENABLE_MAX_ENDSTOPS
      if (isAxisLimitOpen(PIN_X_MAX) || isAxisLimitOpen(PIN_Y_MAX)) {
        triggerHardFault(F("Positive-end limit tripped during pre-homing backoff"));
        return;
      }
#endif
      if (millis() - preStart > BACKOFF_TIMEOUT_MS) {
        triggerHardFault(F("Pre-homing backoff timeout"));
        return;
      }
      stepperX.run();
      stepperY.run();
      serviceSerialDuringHoming();
    }
    // If switch STILL reads HIGH after +10 mm backoff, NC wire is broken/unplugged or stuck!
    if (isAxisLimitOpen(PIN_X_HOME) || isAxisLimitOpen(PIN_Y_HOME)) {
      triggerHardFault(F("X/Y NC home switch stuck open or wire broken"));
      return;
    }
  }

  // 3. Step- & time-bounded seek to X & Y Normally-Closed home switches at 20 mm/s
  //    Guards against missing switches or belt slip exceeding MAX_TRAVEL + 25 mm margin.
  stepperX.setCurrentPosition(0);
  stepperY.setCurrentPosition(0);
  unsigned long homeStartMs = millis();
  while (!isAxisLimitOpen(PIN_X_HOME) || !isAxisLimitOpen(PIN_Y_HOME)) {
    if (isEstopActive()) {
      triggerHardFault(F("E-Stop triggered during homing seek"));
      return;
    }
#if Z_LIMIT_IS_OVERTRAVEL
    if (isAxisLimitOpen(PIN_Z_HOME)) {
      triggerHardFault(F("Z overtravel limit tripped during homing seek"));
      return;
    }
#endif
    if (labs(stepperX.currentPosition()) > MAX_HOMING_SEEK_X_STEPS) {
      triggerHardFault(F("Homing X seek exceeded MAX_HOMING_SEEK_X_MM (395 mm): switch/belt fault"));
      return;
    }
    if (labs(stepperY.currentPosition()) > MAX_HOMING_SEEK_Y_STEPS) {
      triggerHardFault(F("Homing Y seek exceeded MAX_HOMING_SEEK_Y_MM (325 mm): switch/belt fault"));
      return;
    }
    if (millis() - homeStartMs > HOMING_TIMEOUT_MS) {
      triggerHardFault(F("Homing seek timeout (>23s): stall, belt slip, or switch failure"));
      return;
    }
    if (!isAxisLimitOpen(PIN_X_HOME)) {
      stepperX.setSpeed(-HOMING_SPEED_STEPS);
      stepperX.runSpeed();
    }
    if (!isAxisLimitOpen(PIN_Y_HOME)) {
      stepperY.setSpeed(-HOMING_SPEED_STEPS);
      stepperY.runSpeed();
    }
    serviceSerialDuringHoming();
  }

  // 4. Back off 3.0 mm off switches and VERIFY switches re-close (LOW) within timeout
  stepperX.setCurrentPosition(0);
  stepperY.setCurrentPosition(0);
  stepperX.moveTo(lroundf(3.0f * STEPS_PER_MM_X));
  stepperY.moveTo(lroundf(3.0f * STEPS_PER_MM_Y));
  unsigned long releaseStartMs = millis();
  while (!isGantryAtTarget()) {
    if (isEstopActive()) {
      triggerHardFault(F("E-Stop triggered during homing switch release"));
      return;
    }
    if (millis() - releaseStartMs > BACKOFF_TIMEOUT_MS) {
      triggerHardFault(F("Homing switch release backoff timeout"));
      return;
    }
    stepperX.run();
    stepperY.run();
    serviceSerialDuringHoming();
  }
  if (isAxisLimitOpen(PIN_X_HOME) || isAxisLimitOpen(PIN_Y_HOME)) {
    triggerHardFault(F("X/Y home switch did not re-close after 3mm backoff"));
    return;
  }

  stepperX.setCurrentPosition(0);
  stepperY.setCurrentPosition(0);

  // 5. Restore operating speed (2800 steps/s = 70 mm/s) & acceleration (6000 steps/s^2 = 150 mm/s^2)
  stepperX.setMaxSpeed(MAX_SPEED_STEPS);
  stepperX.setAcceleration(ACCEL_STEPS);
  stepperY.setMaxSpeed(MAX_SPEED_STEPS);
  stepperY.setAcceleration(ACCEL_STEPS);

  // Drain any stale bytes before declaring READY
  while (Serial1.available() > 0) {
    Serial1.read();
  }

  isHomed         = true;
  lastHeartbeatMs = millis();
  currentState    = STATE_IDLE;
  Serial1.write(CMD_STATUS_READY);
  Serial.println(F("[READY] Homing complete. Gantry at (0, 0)."));
}

bool readSerial1Bytes(uint8_t *dest, uint16_t len, unsigned long timeoutMs) {
  // Called only during STATE_IDLE when steppers are stationary; drains 64B FIFO at max rate
  unsigned long start = millis();
  uint16_t idx = 0;
  while (idx < len) {
    if (isEstopActive()) {
      triggerHardFault(F("E-Stop triggered during batch receive"));
      return false;
    }
    if (Serial1.available() > 0) {
      dest[idx++] = (uint8_t)Serial1.read();
    } else if (millis() - start > timeoutMs) {
      return false;
    }
  }
  return true;
}

void pollVisionHostPackets() {
  while (Serial1.available() > 0) {
    uint8_t peekByte = (uint8_t)Serial1.read();

    // 1. Explicit Host Readiness Query
    if (peekByte == CMD_QUERY_STATUS) {
      replyStatusQuery();
      continue;
    }

    // 2. Heartbeat Keep-Alive Ping (never auto-clears faults or initiates motion!)
    if (peekByte == CMD_HEARTBEAT_PING) {
      lastHeartbeatMs = millis();
      continue;
    }

    // 3. Explicit Operator Re-Arm & Re-Home Command from Fault/Halt State
    if (peekByte == CMD_REARM_HOME) {
      if (currentState == STATE_FAILSAFE_HALT || currentState == STATE_HARD_FAULT) {
        if (isEstopActive()) {
          Serial.println(F("[REARM_REJECTED] Release physical E-Stop before re-arming."));
          Serial1.write(CMD_STATUS_FAULT);
          continue;
        }
        Serial.println(F("[REARM] Explicit re-arm accepted; starting full re-home."));
        homeAxes();
      } else {
        replyStatusQuery();
      }
      continue;
    }

    // 4. Closed-Loop Clear-FOV Park Command (move gantry to (0,0) for unobstructed verification scan)
    if (peekByte == CMD_PARK_FOR_SCAN) {
      if ((currentState != STATE_AWAIT_NEXT_TARGET && currentState != STATE_IDLE) ||
          !isHomed || commsFaultLatched || isEstopActive()) {
        Serial1.write(CMD_BATCH_NACK);
        continue;
      }
      if (!isZSafeForXYMotion()) {
        triggerHardFault(zUnsafeReason());
        return;
      }
      closedLoopMode  = true;
      lastHeartbeatMs = millis();
      moveMachineToMm(0.0f, 0.0f);
      currentState    = STATE_PARKING_FOR_SCAN;
      continue;
    }

    // 5. Closed-Loop Session Finish Command (park at (0,0) if needed, emit COMPLETE -> IDLE)
    if (peekByte == CMD_FINISH_SESSION) {
      if ((currentState != STATE_AWAIT_NEXT_TARGET && currentState != STATE_IDLE) ||
          !isHomed || commsFaultLatched || isEstopActive()) {
        Serial1.write(CMD_BATCH_NACK);
        continue;
      }
      if (!isZSafeForXYMotion()) {
        triggerHardFault(zUnsafeReason());
        return;
      }
      closedLoopMode  = false;
      lastHeartbeatMs = millis();
      moveMachineToMm(0.0f, 0.0f);
      currentState    = STATE_PARKING_HOME;
      continue;
    }

    // 6. Closed-Loop Single-Target Pick Packet: [0x5B][CapTarget 15B][CRC16 2B] (18B total)
    if (peekByte == PROTOCOL_SINGLE_MAGIC) {
      bool canAccept = (currentState == STATE_IDLE || currentState == STATE_AWAIT_NEXT_TARGET);
      if (!canAccept || !isHomed || commsFaultLatched || isEstopActive()) {
        Serial1.write(CMD_BATCH_NACK);
        continue;
      }

      CapTarget rxCap;
      uint8_t crcBuf[2];
      if (!readSerial1Bytes((uint8_t*)&rxCap, sizeof(CapTarget), 250) ||
          !readSerial1Bytes(crcBuf, 2, 100)) {
        if (currentState == STATE_IDLE || currentState == STATE_AWAIT_NEXT_TARGET) {
          Serial1.write(CMD_BATCH_NACK);
        }
        return;
      }

      uint16_t rxCrc   = (uint16_t)crcBuf[0] | ((uint16_t)crcBuf[1] << 8);
      uint16_t calcCrc = computeCRC16((const uint8_t*)&rxCap, sizeof(CapTarget));
      if (calcCrc != rxCrc || !isValidSingleTarget(rxCap)) {
        Serial1.write(CMD_BATCH_NACK);
        return;
      }

      if (!isZSafeForXYMotion()) {
        triggerHardFault(zUnsafeReason());
        return;
      }

      // Valid closed-loop target! Move directly from current pose (0,0 or bin) to cap
      closedLoopMode        = true;
      batchTotal            = 1;
      currentIdx            = 0;
      currentCap            = rxCap;
      hasInFlightCap        = false;
      capPossessionVerified = false;
      commsFaultLatched     = false;
      lastHeartbeatMs       = millis();
      Serial1.write(CMD_BATCH_ACK);

      moveBoardToMm(currentCap.boardX_mm, currentCap.boardY_mm);
      currentState = STATE_MOVING_TO_CAP;
      return;
    }

    // 7. Legacy Multi-Cap Batch Header (ONLY accepted when homed, fault-free, and IDLE)
    if (peekByte == PROTOCOL_MAGIC_BYTE) {
      if (currentState != STATE_IDLE || !isHomed || commsFaultLatched || isEstopActive()) {
        Serial1.write(CMD_BATCH_NACK);
        continue;
      }

      BatchHeader hdr;
      hdr.magic = PROTOCOL_MAGIC_BYTE;
      if (!readSerial1Bytes(((uint8_t*)&hdr) + 1, sizeof(BatchHeader) - 1, 250)) {
        if (currentState == STATE_IDLE) Serial1.write(CMD_BATCH_NACK);
        return;
      }
      if (hdr.totalCaps == 0 || hdr.totalCaps > MAX_BATCH_CAPS) {
        Serial1.write(CMD_BATCH_NACK);
        return;
      }

      uint16_t payloadBytes = (uint16_t)hdr.totalCaps * sizeof(CapTarget);
      if (!readSerial1Bytes((uint8_t*)batchQueue, payloadBytes, 1500)) {
        if (currentState == STATE_IDLE) Serial1.write(CMD_BATCH_NACK);
        return;
      }

      uint16_t calcCrc = computeCRC16((const uint8_t*)batchQueue, payloadBytes);
      if (calcCrc != hdr.crc16) {
        Serial1.write(CMD_BATCH_NACK);
        return;
      }
      for (uint8_t i = 0; i < hdr.totalCaps; i++) {
        if (!isValidSingleTarget(batchQueue[i])) {
          Serial1.write(CMD_BATCH_NACK);
          return;
        }
      }

      if (!isZSafeForXYMotion()) {
        triggerHardFault(zUnsafeReason());
        return;
      }

      // Valid legacy batch received! Store locally & acknowledge
      closedLoopMode        = false;
      batchTotal            = hdr.totalCaps;
      currentIdx            = 0;
      hasInFlightCap        = false;
      capPossessionVerified = false;
      commsFaultLatched     = false;
      lastHeartbeatMs       = millis();
      Serial1.write(CMD_BATCH_ACK);

      // Start Step 01 on first target cap
      currentCap = batchQueue[0];
      moveBoardToMm(currentCap.boardX_mm, currentCap.boardY_mm);
      currentState = STATE_MOVING_TO_CAP;
    }
  }
}

void checkRuntimeSafetyInputs() {
  if (currentState == STATE_HOMING || currentState == STATE_HARD_FAULT) return;

  unsigned long nowMs = millis();

  // Priority 1: Auxiliary NC E-Stop contact (timed persistence >= ESTOP_DEBOUNCE_MS + >= 2 samples)
  // Note: Pole 1 already cuts 12V actuator power directly in hardware independent of loop timing.
  if (isEstopActive()) {
    if (estopFaultCount == 0) {
      estopHighSinceMs = nowMs;
    }
    if (estopFaultCount < 255) estopFaultCount++;
    if (estopFaultCount >= 2 && (nowMs - estopHighSinceMs >= ESTOP_DEBOUNCE_MS)) {
      triggerHardFault(F("Physical E-Stop auxiliary contact open"));
      return;
    }
  } else {
    estopFaultCount  = 0;
    estopHighSinceMs = 0;
  }

  // Priority 2: Polled NC limit switches for X, Y, and Z (timed persistence >= LIMIT_DEBOUNCE_MS + >= 3 samples)
  if (isAnyOvertravelLimitOpen()) {
    if (limitFaultCount == 0) {
      limitOpenSinceMs = nowMs;
    }
    if (limitFaultCount < 255) limitFaultCount++;
    if (limitFaultCount >= 3 && (nowMs - limitOpenSinceMs >= LIMIT_DEBOUNCE_MS)) {
      triggerHardFault(F("Runtime X/Y/Z NC limit switch open or broken wire"));
    }
  } else {
    limitFaultCount  = 0;
    limitOpenSinceMs = 0;
  }
}

bool checkCommunicationLoss() {
  if (currentState == STATE_IDLE || currentState == STATE_HOMING ||
      currentState == STATE_FAILSAFE_PARKING || currentState == STATE_FAILSAFE_HALT ||
      currentState == STATE_HARD_FAULT || commsFaultLatched) {
    return false;
  }
  return (millis() - lastHeartbeatMs > COMMS_TIMEOUT_MS);
}

void executeSafeCommsLossPolicy() {
  commsFaultLatched = true;
  Serial1.write(CMD_RECOVERY_HALT);

  // If a single scanned cap has already been dispatched and is currently in its
  // active pick-and-place cycle, finish ONLY that active commanded cycle,
  // then park cleanly at (0, 0) via STATE_FAILSAFE_PARKING and latch halt.
  // (Hardwired E-stop Pin 25 and NC X/Y/Z limits remain active at all times.)
  bool inActiveCapCycle = (currentState == STATE_MOVING_TO_CAP ||
                           currentState == STATE_LOWER_Z ||
                           currentState == STATE_GRIP_CAP ||
                           currentState == STATE_LIFT_Z ||
                           currentState == STATE_TRAVERSE_BIN ||
                           currentState == STATE_BIN_SETTLE ||
                           currentState == STATE_LOWER_BIN ||
                           currentState == STATE_RELEASE_CAP ||
                           currentState == STATE_RETRACT_Z);
  if (inActiveCapCycle) {
    batchTotal = 0; // Do not start any further queued caps after this one
#if HAS_GRIP_SENSOR
    Serial.println(F("[COMMS_LOSS] Finishing active verified pick-place cycle, then parking at (0,0) to halt."));
#else
    Serial.println(F("[COMMS_LOSS] Finishing active commanded pick-place cycle (cap possession unverified without HAS_GRIP_SENSOR), then parking at (0,0) to halt."));
#endif
    return;
  }

  // No cap currently active (e.g., awaiting next target at bin or parking):
  // Confirm Z safety state, park cleanly at (0, 0), disable steppers,
  // and latch STATE_FAILSAFE_HALT until explicit CMD_REARM_HOME + re-home.
  pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
  pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_OPEN);
  if (!isZSafeForXYMotion()) {
    triggerHardFault(zUnsafeReason());
    return;
  }
  closedLoopMode        = false;
  hasInFlightCap        = false;
  capPossessionVerified = false;
  batchTotal            = 0;
  currentIdx            = 0;
  moveMachineToMm(0.0f, 0.0f);
  currentState          = STATE_FAILSAFE_PARKING;
  Serial.println(F("[COMMS_LOSS] No active cycle; parking at (0,0) then latching fail-safe halt."));
}

void executeMotionStateMachine() {
  switch (currentState) {
    case STATE_IDLE:
    case STATE_HOMING:
    case STATE_AWAIT_NEXT_TARGET:
    case STATE_FAILSAFE_HALT:
    case STATE_HARD_FAULT:
      break;

    // Step 01: Traverse to Cap (X, Y) with Z raised and Gripper open
    case STATE_MOVING_TO_CAP:
      if (isGantryAtTarget()) {
        pca.setPWM(SERVO_Z_CH, 0, PWM_Z_LOWER_PICK);
        stateTimerMs = millis();
        currentState = STATE_LOWER_Z;
      }
      break;

    // Step 02: Lower Z linkage (~40 mm) over cap
    case STATE_LOWER_Z:
      if (millis() - stateTimerMs >= 350) {
        pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_CLOSE);
        stateTimerMs = millis();
        currentState = STATE_GRIP_CAP;
      }
      break;

    // Step 03: Clamp Gripper jaws (~26 mm)
    case STATE_GRIP_CAP:
      if (millis() - stateTimerMs >= 300) {
#if HAS_GRIP_SENSOR
        hasInFlightCap = true;
        if (isCapVerifiedHeld()) {
          capPossessionVerified = true;
          pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
          stateTimerMs = millis();
          currentState = STATE_LIFT_Z;
        } else {
          // Verified empty grasp: open jaws, retract Z, skip false bin drop so vision retries/quarantines
          hasInFlightCap        = false;
          capPossessionVerified = false;
          pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_OPEN);
          pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
          stateTimerMs = millis();
          currentState = STATE_RETRACT_Z;
          Serial.println(F("[GRIP_MISS] Cap-presence sensor not triggered; skipping bin drop."));
        }
#else
        hasInFlightCap        = true; // Commanded grip cycle active (physical cap possession UNVERIFIED)
        capPossessionVerified = false;
        pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
        stateTimerMs = millis();
        currentState = STATE_LIFT_Z;
#endif
      }
      break;

    // Step 04: Lift Z linkage back to 0 mm overhead clearance
    case STATE_LIFT_Z:
      if (millis() - stateTimerMs >= 350) {
        if (!isZSafeForXYMotion()) {
          triggerHardFault(zUnsafeReason());
          return;
        }
#if HAS_GRIP_SENSOR
        if (!isCapVerifiedHeld()) {
          // Cap slipped during Z lift: open jaws and abort bin transit cleanly
          hasInFlightCap        = false;
          capPossessionVerified = false;
          pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_OPEN);
          stateTimerMs = millis();
          currentState = STATE_RETRACT_Z;
          Serial.println(F("[GRIP_SLIP] Cap-presence lost during Z lift; aborting bin transit."));
          return;
        }
#endif
        uint8_t binId = currentCap.targetBinId;
        if (binId < 1 || binId > 4) binId = 1;
        moveMachineToMm(BIN_X_MM[binId], BIN_Y_MM[binId]);
        currentState = STATE_TRAVERSE_BIN;
      }
      break;

    // Step 05: Traverse to designated color bin; pause briefly to settle before bin-side capture
    case STATE_TRAVERSE_BIN:
      if (isGantryAtTarget()) {
        if (closedLoopMode && !commsFaultLatched) {
          stateTimerMs = millis();
          currentState = STATE_BIN_SETTLE;
        } else {
          pca.setPWM(SERVO_Z_CH, 0, PWM_Z_LOWER_BIN);
          stateTimerMs = millis();
          currentState = STATE_LOWER_BIN;
        }
      }
      break;

    // Step 05b: Stationary 120 ms XY settle at bin (Z raised) -> trigger pipelined camera scan
    case STATE_BIN_SETTLE:
      if (commsFaultLatched || (millis() - stateTimerMs >= BIN_SETTLE_MS)) {
        if (!commsFaultLatched) {
          Serial1.write(CMD_SCAN_WINDOW_OPEN);
        }
        pca.setPWM(SERVO_Z_CH, 0, PWM_Z_LOWER_BIN);
        stateTimerMs = millis();
        currentState = STATE_LOWER_BIN;
      }
      break;

    // Step 06: Lower Z partially (~25 mm) into bin opening (in parallel with vision analysis!)
    case STATE_LOWER_BIN:
      if (millis() - stateTimerMs >= 250) {
        pca.setPWM(SERVO_GRIPPER_CH, 0, PWM_GRIP_OPEN);
        stateTimerMs = millis();
        currentState = STATE_RELEASE_CAP;
      }
      break;

    // Step 07: Release Gripper jaws (cap drops into bin)
    case STATE_RELEASE_CAP:
      if (millis() - stateTimerMs >= 250) {
        hasInFlightCap        = false;
        capPossessionVerified = false;
        pca.setPWM(SERVO_Z_CH, 0, PWM_Z_RAISED);
        stateTimerMs = millis();
        currentState = STATE_RETRACT_Z;
      }
      break;

    // Step 08: Retract Z to 0 mm, emit progress pulse, await next closed-loop target or finish
    case STATE_RETRACT_Z:
      if (millis() - stateTimerMs >= 300) {
        if (!isZSafeForXYMotion()) {
          triggerHardFault(zUnsafeReason());
          return;
        }

        Serial1.write(CMD_CAP_PROGRESS);

        if (commsFaultLatched) {
          // Active scanned cap deposit finished; park cleanly at (0,0) then latch halt
          Serial1.write(CMD_RECOVERY_HALT);
          closedLoopMode = false;
          batchTotal     = 0;
          currentIdx     = 0;
          moveMachineToMm(0.0f, 0.0f);
          currentState   = STATE_FAILSAFE_PARKING;
          return;
        }

        if (closedLoopMode) {
          batchTotal = 0;
          currentIdx = 0;
          Serial1.write(CMD_AWAIT_NEXT);
          currentState = STATE_AWAIT_NEXT_TARGET;
          return;
        }

        currentIdx++;
        if (currentIdx < batchTotal) {
          currentCap = batchQueue[currentIdx];
          moveBoardToMm(currentCap.boardX_mm, currentCap.boardY_mm);
          currentState = STATE_MOVING_TO_CAP;
        } else {
          // Legacy batch finished! Return gantry to (0,0) clear of camera FOV
          moveMachineToMm(0.0f, 0.0f);
          currentState = STATE_PARKING_HOME;
        }
      }
      break;

    // Clear-FOV verification park (gantry clears bridge off board, stays in active session)
    case STATE_PARKING_FOR_SCAN:
      if (isGantryAtTarget()) {
        Serial1.write(CMD_AWAIT_NEXT);
        currentState = STATE_AWAIT_NEXT_TARGET;
      }
      break;

    case STATE_PARKING_HOME:
      if (isGantryAtTarget()) {
        closedLoopMode = false;
        batchTotal     = 0;
        currentIdx     = 0;
        Serial1.write(CMD_BATCH_COMPLETE);
        currentState = STATE_IDLE;
      }
      break;

    case STATE_FAILSAFE_PARKING:
      if (isGantryAtTarget()) {
        digitalWrite(PIN_STEPPER_EN, HIGH);
        closedLoopMode        = false;
        isHomed               = false;
        hasInFlightCap        = false;
        capPossessionVerified = false;
        batchTotal            = 0;
        currentIdx            = 0;
        currentState   = STATE_FAILSAFE_HALT;
        Serial1.write(CMD_RECOVERY_HALT);
        Serial.println(F("[COMMS_LOSS] Parked at (0,0) & halted. Explicit re-arm & re-home required."));
      }
      break;
  }
}

void loop() {
  // 1. Poll E-stop auxiliary contact and X/Y/Z NC limit switches
  checkRuntimeSafetyInputs();

  // 2. Step only when actively moving and fault-free
  if (currentState != STATE_HARD_FAULT && currentState != STATE_FAILSAFE_HALT) {
    stepperX.run();
    stepperY.run();
  }

  // 3. Poll host status queries, batch packets, heartbeat pings & re-arm commands
  pollVisionHostPackets();

  // 4. Execute non-blocking 8-step pick-and-place state machine
  executeMotionStateMachine();

  // 5. Watchdog: latch fail-safe halt if UART heartbeat drops during active motion
  if (checkCommunicationLoss()) {
    executeSafeCommsLossPolicy();
  }
}

// Shared CRC16-CCITT implementation (Polynomial 0x1021, Initial 0xFFFF)
static inline uint16_t computeCRC16(const uint8_t* data, uint32_t length) {
  uint16_t crc = 0xFFFF;
  for (uint32_t i = 0; i < length; i++) {
    crc ^= ((uint16_t)data[i] << 8);
    for (uint8_t bit = 0; bit < 8; bit++) {
      if (crc & 0x8000) {
        crc = (crc << 1) ^ 0x1021;
      } else {
        crc = (crc << 1);
      }
    }
  }
  return crc;
}

Critical V2 Engineering Considerations

Essential hardware and Linux edge-computing safeguards specific to the Raspberry Pi Zero 2 W + 8MP IMX219 160° camera architecture.

1. 22-Pin Pi Zero CSI Ribbon Cable

Standard 8MP IMX219 camera modules on Robu.in include a 15-pin (1.0 mm pitch) cable for Pi 3/4. The Raspberry Pi Zero 2 W has a narrower 22-pin (0.5 mm pitch) CSI connector. Always pair the camera with a Pi Zero 15-pin to 22-pin CSI adapter ribbon cable (~₹69).

2. 160° Fisheye Lens Rectification

A 160° wide-angle lens exhibits radial barrel distortion near the perimeter of the 300×300 mm board. A 3×3 planar homography matrix only corrects flat perspective tilt—you must run cv2.fisheye.initUndistortRectifyMap + cv2.remap before applying homography.

3. Read-Only OverlayFS for 16GB SD

Linux microSD cards can suffer ext4 corruption if 12V main power is switched off without running sudo shutdown. Enable OverlayFS (Read-Only Root Filesystem) in raspi-config once calibrated so the Pi Zero 2 W can be safely powered off instantly like a microcontroller.

4. TMC2208 Vref & Pi Heatsink

Inspect the exact Rsense on your TMC2208 carrier (commonly 0.11 Ω). Per ADI TMC2208 Rev 1.13: IRMS = (0.325 / (Rsense + 0.03)) × (Vref / (2.5 × √2)) (~0.75 A RMS at Vref=1.15 V, Rsense=0.11 Ω). Measure driver & Pi heatsink thermals on the bench.

5. Dedicated Servo vs. Pi Power Rail

Never power MG90S servos from the same 5V buck converter feeding the Raspberry Pi Zero 2 W. Use separate regulated branches sharing a common star ground: Branch B (5V/5A Buck) for PCA9685 V+ and Branch C (5V/3A Buck) for Pi + Mega 5V pin. Verify your exact MG90S SKU voltage rating (original TowerPro MG90S is 4.8 V nominal).

6. Locked AWB/AEC & Full-Sensor 1640×1232 Binning

In Picamera2, configuring raw={"size": (1640, 1232)} forces the 8MP IMX219 into 2×2 full-sensor binning before ISP downscaling to 640×480 (preventing center-crop FOV loss), while locking AeEnable=False, AwbEnable=False after warm-up.

7. 16 MHz AVR Step Budget (40 steps/mm)

On an 8-bit 16 MHz ATmega2560, AccelStepper::run() has a ~4,000 steps/s combined ceiling. Running TMC2208 at 1/8 microstepping (40 steps/mm nominal) yields 70 mm/s (2800 steps/s) and 0.025 mm commanded step resolution (open-loop — measure physical accuracy & repeatability on the bench).

8. 64-Byte AVR UART FIFO Pacing & Explicit Re-Arm

pi_zero_vision.py waits for CMD_STATUS_READY, streams batches in 32-byte paced chunks (2 ms pause), and services 0xF0 heartbeats across the entire batch via CMD_CAP_PROGRESS. Any comms-loss halt or E-stop requires explicit operator re-arm (CMD_REARM_HOME) & re-homing — never auto-recovering on heartbeats.

9. Specular Glare Closing, 24mm NMS & NC Wire Guard

MORPH_CLOSE seals specular highlights on glossy cap domes and 24 mm Spatial NMS prevents duplicate picks. On the Mega, Pin 9 holds PCA9685 OE HIGH during boot to eliminate servo twitch and NC switches are monitored continuously in loop().
